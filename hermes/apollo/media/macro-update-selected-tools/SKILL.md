# Krokodove Macro Editor Update from Selected Tools

## When to Use

Use when you need to modify tools on the Fusion flow and seamlessly update the corresponding macro while preserving control selections and layout. New in DaVinci Resolve 21.1.

## Video Reference
- **Video ID:** Wi44XLKQ3YA
- **Timestamp:** 9:21-9:32
- **Resolve Page:** Fusion

## Tool Location
Fusion Effects Library → Krokodove → Macro Editor → Update from Selected Tools

## Workflow
1. Open existing macro in Macro Editor
2. Make changes to tools in Fusion flow
3. Select modified tools in flow
4. Click "Update from Selected Tools" in Macro Editor
4. Macro updates with new tool config
5. Control selections and layout preserved

## Benefits
- Iterative macro development
- Preserve custom UI layouts
- Sync flow changes to macro definition
- Non-destructive experimentation

## Use Cases
- Refine macro parameters after testing
- Add/remove tools from existing macro
- Update expressions without rebuilding UI
- Collaborative macro iteration

## Tips
- Select only the tools you want to update
- Control panel layout stays intact
- Works with published parameters
- Test in flow before updating macro
