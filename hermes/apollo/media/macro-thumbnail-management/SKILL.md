# Krokodove Macro Editor Thumbnail Management

## When to Use

Use when you need to manage macro thumbnail previews in the Macro Editor. New in DaVinci Resolve 21.1.

## Video Reference
- **Video ID:** Wi44XLKQ3YA
- **Timestamp:** 9:14-9:20
- **Resolve Page:** Fusion

## Tool Location
Fusion Effects Library → Krokodove → Macro Editor → Thumbnail controls

## Features
- Clear thumbnails for selected macros
- Regenerate thumbnails from current state
- Batch thumbnail operations
- Custom thumbnail assignment

## Workflow
1. Open Macro Editor
2. Select macro(s) in list
3. Right-click → "Clear Thumbnail" or "Regenerate Thumbnail"
4. For custom: "Set Thumbnail" → select image file
5. Thumbnails update in Effects Library

## Use Cases
- Fix outdated/incorrect macro previews
- Create consistent visual library
- Brand macro collections
- Remove clutter from template browser

## Tips
- Clear thumbnails before major macro updates
- Use 16:9 ratio for best display
- Batch process for large libraries
- Custom thumbnails survive macro edits
