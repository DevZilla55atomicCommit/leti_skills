# Krokodove Macro Editor Save To Template Category

## When to Use

Use when you need to save macro definitions to specific template categories for organization across Edit/Cut pages. New in DaVinci Resolve 21.1.

## Video Reference
- **Video ID:** Wi44XLKQ3YA
- **Timestamp:** 9:03-9:13
- **Resolve Page:** Fusion

## Tool Location
Fusion Effects Library → Krokodove → Macro Editor → Save To dropdown

## Workflow
1. Create or modify macro in Macro Editor
2. Click "Save To" dropdown
3. Select target category (Edit Templates, Cut Templates, Custom)
4. Choose or create subfolder
5. Name macro template
6. Macro appears in selected page's Effects Library

## Template Categories
| Category | Location | Use Case |
|----------|----------|----------|
| Edit Templates | Edit page Effects Library | Transitions, titles, effects |
| Cut Templates | Cut page Effects Library | Quick-cut tools |
| Custom | User-defined folder | Project-specific macros |
| Favorites | Quick access bar | Frequently used |

## Tips
- Organize by project type (commercial, narrative, social)
- Use consistent naming: "Category_Description_v1"
- Share folders across team via network path
- Version macros with date/iteration in name
