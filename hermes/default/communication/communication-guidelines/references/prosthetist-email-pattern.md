# Prosthetist Clinical Email Pattern

## Context
User (Alfred) communicates with prosthetist (Sandeep Rout, Hanger Clinic) about complex wound management issues requiring prosthetic fitting intervention. Emails need to be clinically precise, convey urgency, and prompt specific clinical actions.

## User Preferences (from session 2026-08-31)
1. **Subject line must lead with clinical urgency** — "Urgent:" + clinical problem + action requested
2. **Bold key clinical facts** for skim readability (duration, mechanism, complicating factors, specific ask)
3. **Numbered asks** give concrete actions, not vague concern
4. **Close with cycle framing** — "admit → heal → re-admit" positions as systems failure the specialist can fix
5. **Terminology precision** — "pressure sores" not "friction sores" (clinical accuracy)

## Template Structure
```
Subject: Urgent: [Clinical Problem] — [Specific Ask] Before [Appt Date]

Hi [Prosthetist Name],

My wound care specialist and I discussed my ongoing [wound location] wound today. They're concerned this has persisted for [duration] and emphasized that **unless the prosthetic fitting is corrected and aligned properly, the wound will continue to cycle — healed or not.**

Key points they want you aware of:

- **[Wound location]-side wound** — [status] since [date]; primary admission driver
- **Mechanism** — pressure sores → blisters → open wounds within days of wear
- **Complicating factor** — high-dose [anticoagulant] (anticoagulation): bleeding/bruising risk amplifies tissue breakdown
- **Specialist's ask** — please **monitor and examine the fitting thoroughly** at next visit; current alignment appears to be the root cause

My next appointment with you is **[Date] ([timeframe] from now)**. Would you be open to:

1. Allocating extra time for a detailed fitting assessment at that visit?
2. Sharing any interim adjustment recommendations before then?
3. Confirming whether a temporary liner/socket modification could reduce [location] pressure in the meantime?

This has been a [duration] cycle of admission → heal → re-admit. Both my wound team and I believe the prosthetic interface is the variable that hasn't been fully addressed. I'd value your clinical judgment on the best path to break that cycle.

Best regards,
Alfred
```
