# Medical Supply Status Email Pattern

## Context
User (Alfred) communicates with wound care nurse (Althea, RN) about supply status between appointments. Emails follow a concise, status-list format.

## User Preferences (from corrections in session)
1. **Status list** – Only clinical supplies provided by the care team (Mepilex, Iodosorb). Personal supplies (Band-Aid) go in the narrative, not the status list.
2. **No "no additional supplies needed" line** – User removed this as redundant.
3. **Bottom narrative** – Personal supply bridging ("I can use Band-Aid until then as well") goes after the status list, before the closing.
4. **Concise, direct** – Bullet status, one narrative sentence, standard closing.

## Template Structure
```
Subject: Re: Wound Care Supplies Update

Hi [Nurse Name],

Thanks for following up. Quick status:

- **[Supply 1]** – [status]
- **[Supply 2]** – [status]

[Clinical supply] will cover me until my [appointment day/time] appointment. [Personal supply bridging note if applicable].

I'll update you if anything changes before then.

Best,
Alfred
```

## Example (from session)
- Mepilex Border gauze → already out (status list)
- Iodosorb gel → have enough to last through Monday (status list)
- Band-Aid → "I can use Band-Aid until then as well" (narrative only)
