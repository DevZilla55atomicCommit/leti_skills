## Steps

1. Open the Color page and create a new Serial Node for noise reduction.
2. Open the Noise Reduction panel (far right of the Color page).
3. Enable **Spatial Noise Reduction** and set Mode to "Better" (3).
4. Adjust **Spatial Threshold** (20-40) - higher removes more noise but softens detail.
5. Set **Spatial Radius** to 1-2 for the blur size.
6. Enable **Temporal Noise Reduction** and set **Frames** to 3-5.
7. Adjust **Temporal Threshold** (15-30) for temporal noise removal.
8. Set **Temporal Radius** to 1-2.
9. Use the "Preview" checkbox to compare before/after.
10. Apply a light Sharpening in a separate node if detail is lost.
