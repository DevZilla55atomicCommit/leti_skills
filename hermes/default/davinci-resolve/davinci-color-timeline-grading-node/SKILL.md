## Steps

1. Go to the Color page in DaVinci Resolve.
2. Right-click in the Node Graph area and select "Add Timeline Grade" (or use the Timeline Grade button).
3. A new Timeline Grade node appears at the end of your node chain.
4. Apply any color adjustments (Lift/Gamma/Gain, Curves, LUTs, etc.) to this node.
5. The grade will apply to ALL clips on the timeline, not just the current clip.
6. Use keyframes on the Timeline Grade node to animate the look over time.
7. Switch between Clip Grade and Timeline Grade modes as needed.
