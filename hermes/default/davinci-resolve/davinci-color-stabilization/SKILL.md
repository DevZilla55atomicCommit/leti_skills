## Steps

1. Select the clip in the Timeline that needs stabilization.
2. Open the Inspector panel on the Edit page.
3. Scroll down to the "Stabilization" section.
4. Set the Mode to "Perspective" for the most robust stabilization.
4. Adjust the "Smoothing" slider to control how much the camera movement is smoothed (higher = smoother but more zoom).
5. Set "Framing Scalar" to "Zoom to Fit" to automatically crop the stabilized footage.
5. Click "Stabilize" to analyze and apply the stabilization.
6. Review the result and adjust Smoothing/Framing as needed.
