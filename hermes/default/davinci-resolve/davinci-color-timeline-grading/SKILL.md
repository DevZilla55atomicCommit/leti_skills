## Steps

1. Open the Color page in DaVinci Resolve.
2. In the node graph area, right-click and select "Add Timeline Grade Node".
3. This creates a node that affects ALL clips on the timeline simultaneously.
4. Apply a creative LUT or color grade to this Timeline Grade node.
5. Use the Color Wheels and Curves on this node for global adjustments.
6. The Timeline Grade sits at the end of the node chain for every clip.
7. Individual clip grades (clip nodes) happen BEFORE the Timeline Grade.
