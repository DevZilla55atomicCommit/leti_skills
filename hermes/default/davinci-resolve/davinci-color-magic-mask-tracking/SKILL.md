## Steps

1. Import the tree trunk footage and go to the Color Page.
2. Create a new Serial Node for the mask.
3. Select the Magic Mask tool (AI-powered).
4. Click on the tree trunk to let Resolve automatically detect and isolate it.
5. Go to the Tracker panel and click "Track Forward" to follow the trunk movement.
5. Refine the mask with a Power Window if needed for clean edges.
6. Apply color adjustments (clarity, saturation, dehaze) only to the masked area.
7. Add a soft edge to the mask for natural blending.
