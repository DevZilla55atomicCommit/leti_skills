# Filmic Glow / Soft Diffusion Effect

**Resolve Page:** Color  
**Node Graph:** Serial  
**Key Nodes:** Primary Correction, Qualifier or Power Mask, Gaussian Blur, Blending Mode adjustment

## Parameters

| Parameter | Value |
|-----------|-------|
| Blur Radius | High (50-100) |
| Node Blend Mode | Screen or Soft Light |
| Opacity | 0.3 - 0.6 |
| Highlight Selection | Luma Qualifier (targeting the brightest areas) |

## Steps

1. Create a new Serial Node after your primary color grade.
2. Use the Qualifier to select only the highlights of the image (or use a Power Mask to isolate bright areas).
3. Apply a Gaussian Blur to this node, significantly increasing the radius to create a soft haze.
4. Change the Node Blend Mode of this specific node from 'Normal' to 'Screen' or 'Soft Light'.
5. Adjust the Opacity slider of the node until the glow appears natural and subtle without losing detail in the highlights.
