## Steps

2. Create a new Serial Node and use a Power Window or Qualifier to select only highlight areas (lights, sky, wet reflections).
3. Apply the 'Glow' effect to this masked node, increasing the Radius and Lightness to create a dreamy bleed-out.

4. Use Tone Curves to fine-tune the blacks and whites to ensure the image remains moody despite the glow.
