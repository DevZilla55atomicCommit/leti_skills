## Steps

1. Navigate to the Color Page in DaVinci Resolve.
2. Create a new Serial Node for the shadow pass.
3. Open the Smart Adjustments tab in the Inspector.
4. Select the Qualifier tool and switch the mode to Luma Range.
5. Adjust the Luma Range sliders to isolate only the black/shadow areas of the footage.
6. Increase the Clarity (set to Natural) with a value of 5.
7. Increase the Structure to 5 to add detail to the shadows.
8. Apply a Dehaze amount of 16 to increase contrast in the dark areas.
9. Set Shadow Tone to Auto to maintain natural color balance.
