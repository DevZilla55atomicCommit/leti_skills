# Subject Isolation via Power Window and Tracking

**Resolve Page:** Color  
**Node Graph:** Serial  
**Key Nodes:** Primary Color Node, Power Window (Mask), Tracker  

**Source Reel:** @bydasttann (Instagram: CybOdj3Rk-y)

## Parameters

| Parameter | Value |
|-----------|-------|
| Power Window Shape | Circle or Custom Curve |
| Soft Edge | High (to blend mask edges) |
| Saturation | Increased on subject |
| Contrast | Increased slightly on subject |
| Midtone Saturation | Decreased on background (via separate node) |

## Steps

1. Import the clip into the Color page and create a primary node for global color correction.
2. Create a second serial node (Alt+S) specifically for the subject adjustments.
3. Select the Power Window tool and draw a mask around the subject's head and body.
4. Go to the Tracker panel and click 'Track' to ensure the mask follows the subject's movement.
5. Increase the 'Soft Edge' setting on the window to ensure the transition between subject and background is seamless.
6. In the subject-specific node, increase Saturation and Contrast to make the person 'pop'.
7. Create a third node to slightly desaturate or lower the exposure of the background to further isolate the subject.
