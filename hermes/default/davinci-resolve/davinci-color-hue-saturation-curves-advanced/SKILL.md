# Selective Color Desaturation via Hue Curves

## Steps

1. Open the Color Page in DaVinci Resolve.
2. Create a new Serial Node (Alt+S).
3. Open the Curves palette and select the Hue Curves tab.
3. Click the color picker tool (eyedropper) and click on the magenta/purple areas in the viewer to select them.
4. Refine the selection using Clean Matte and HSL de-selection to ensure only the desired color is selected.
5. On the Saturation curve, drag the point down to the left to decrease the saturation of that specific color.
6. Adjust Saturation and Lightness sliders to fine-tune the look.
