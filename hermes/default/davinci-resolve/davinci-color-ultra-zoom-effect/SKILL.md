## Steps

3. Set a keyframe for Zoom at the start (scale 1.0).
4. Move playhead to where you want the zoom to end.
5. Increase Zoom to 2.0-2.5 and set another keyframe.
6. Right-click the keyframes and select Ease In for first, Ease Out for last.
7. Adjust Anchor Point to keep the subject centered during zoom.
8. Add slight Position keyframes if needed to pan while zooming.
