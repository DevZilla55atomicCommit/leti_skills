## Steps

1. Go to the Edit page in DaVinci Resolve.
2. Open the Project Settings (gear icon).
3. Navigate to "Master Settings" > "Optimized Media and Render Cache".
5. Set "Enable background caching after" to 5 seconds.
6. Check "Automatically cache transitions in user mode".
6. Set Render Cache format to ProRes 422 HQ or DNxHR HQX.
7. Click Save.
8. Resolve will now automatically cache clips and transitions in the background after 5 seconds of inactivity.
