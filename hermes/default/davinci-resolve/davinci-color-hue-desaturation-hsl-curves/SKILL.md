## Steps

1. Go to the Color page and select your clip.
2. Create a new Serial Node (Alt+S).
3. Open the HSL Curves palette.
4. Use the Hue Picker (eyedropper) to click on the color in the viewer you wish to remove (e.g., green).
5. Refine the selection using the Qualifier tools to ensure only the desired color is selected.
6. On the Saturation curve, drag the point down to -100 to remove the color.
7. Adjust the Hue curve point to -100 if you wish to shift the color to a different spectrum before desaturating.
