## Steps

1. Open the Color Page in DaVinci Resolve.
2. Create a new Serial Node (Alt+S).
3. Open the Curves palette and select the Hue Curves tab.
4. Click the color picker tool and click on the magenta/purple areas in the viewer to select them.
5. Drag the point on the curve line downward to the left to decrease the saturation of that specific color.
6. Adjust Saturation and Lightness sliders to fine-tune the look.
