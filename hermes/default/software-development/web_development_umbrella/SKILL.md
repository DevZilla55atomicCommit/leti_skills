# Web Development Umbrella Skill

This umbrella skill covers professional web development capabilities for Claude Code, focusing on creating production-ready websites, UI/UX design integration, performance optimization, and deployment workflows.

## Core Capabilities
- Responsive UI development with design system adherence
- Frontend architecture and component libraries
- Performance optimization (LCP, CLS, CLS)
- Deployment pipelines (Vercel, Netlify, Docker)
- Accessibility compliance (WCAG 2.1)
- Design token management
- WebGL and interactive media integration
- Multi-platform design translation (desktop → mobile → web)
