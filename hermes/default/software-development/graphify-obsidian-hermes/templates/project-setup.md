# Project Setup Template for Graphify + Hermes + Obsidian

Use this when starting a new project to quickly set up Graphify integration.

## Quick Start Script

Save as `setup-graphify.sh` in your project root:

```bash
#!/usr/bin/env bash
# setup-graphify.sh - One-command Graphify + Hermes + Obsidian setup
# Usage: ./setup-graphify.sh [vault-subfolder-name]

set -euo pipefail

PROJECT_ROOT="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
VAULT_SUBFOLDER="${1:-Graphify-$(basename "$PROJECT_ROOT")}"
VAULT_PATH="/Users/alfredkamisese/TamaZila Obsidian Vault/$VAULT_SUBFOLDER"

echo "=== Graphify Setup for $(basename "$PROJECT_ROOT") ==="
echo "Project: $PROJECT_ROOT"
echo "Vault:   $VAULT_PATH"
echo ""

# 1. Ensure Graphify is installed
if ! command -v graphify &> /dev/null; then
    echo "Installing Graphify..."
    uv tool install graphifyy
    uv tool update-shell
    source ~/.zshenv
fi

# 2. Install Hermes skill (project-scoped)
echo "Installing Graphify skill for Hermes (project-scoped)..."
graphify hermes install --project

# 3. Build initial graph
echo "Building knowledge graph..."
cd "$PROJECT_ROOT"
graphify .

# 4. Export to Obsidian vault
echo "Exporting to Obsidian vault..."
graphify export obsidian --dir "$VAULT_PATH"

# 5. Install git hooks for auto-rebuild
echo "Installing git hooks..."
graphify hook install

echo ""
echo "=== Setup Complete ==="
echo ""
echo "Next steps:"
echo "  1. Open Obsidian → 'Open folder as vault' → $VAULT_PATH"
echo "  2. Enable Canvas, Graph View, Dataview plugins"
echo "  3. In Hermes, use /graphify to query the graph"
echo "  4. After code changes: graphify update ."
echo ""
echo "Files created:"
echo "  - AGENTS.md (Hermes integration)"
echo "  - .hermes/skills/graphify/SKILL.md (project skill)"
echo "  - graphify-out/ (knowledge graph)"
echo "  - $VAULT_PATH/ (Obsidian vault export)"
```

Make executable: `chmod +x setup-graphify.sh`

## Project AGENTS.md Template (Auto-generated by `graphify hermes install --project`)

```markdown
## graphify

This project has a knowledge graph at graphify-out/ with god nodes, community structure, and cross-file relationships.

When the user types `/graphify`, use the installed graphify skill or instructions before doing anything else.

Rules:
- For codebase questions, first run `graphify query "<question>"` when graphify-out/graph.json exists. Use `graphify path "<A>" "<B>"` for relationships and `graphify explain "<concept>"` for focused concepts. These return a scoped subgraph, usually much smaller than GRAPH_REPORT.md or raw grep output.
- Dirty graphify-out/ files are expected after hooks or incremental updates; dirty graph files are not a reason to skip graphify. Only skip graphify if the task is about stale or incorrect graph output, or the user explicitly says not to use it.
- If graphify-out/wiki/index.md exists, use it for broad navigation instead of raw source browsing.
- Read graphify-out/GRAPH_REPORT.md only for broad architecture review or when query/path/explain do not surface enough context.
- After modifying code, run `graphify update .` to keep the graph current (AST-only, no API cost).
```

## Git Hook Integration

After `graphify hook install`, these are added:

**`.git/hooks/post-commit`**:
```bash
#!/bin/sh
# graphify post-commit hook
graphify update . >/dev/null 2>&1 || true
```

**`.git/hooks/post-checkout`**:
```bash
#!/bin/sh
# graphify post-checkout hook
graphify update . >/dev/null 2>&1 || true
```

**`.git/config`** (merge driver for graph.json):
```ini
[merge "graphify"]
    name = Graphify graph.json union merge
    driver = python -m graphify.merge_driver %O %A %B %P
```

## Obsidian Vault Settings (Recommended)

In your Graphify vault (`Graphify-Project/`), configure:

**Settings → Core Plugins → Enable**:
- ✅ Canvas
- ✅ Graph View
- ✅ Dataview (for live community queries)

**Settings → Community Plugins → Install**:
- Graph Analysis (enhanced graph view)
- Various Complements (wikilink autocomplete)

**Graph View Settings**:
- Groups: Should auto-load from `.obsidian/graph.json`
- Colors: Community-based (10 distinct colors)
- Force-directed layout works well for code graphs

## Verification Checklist

After setup, verify:

- [ ] `graphify --version` works
- [ ] `/graphify` works in Hermes (shows usage)
- [ ] `graphify .` builds graph in project
- [ ] `graphify query "test"` returns results
- [ ] `graphify export obsidian --dir ...` creates vault
- [ ] Vault opens in Obsidian with Canvas + Graph View
- [ ] `graphify update .` works after code change
- [ ] `graphify hook status` shows installed
- [ ] Git commit triggers auto-update (check `graphify-out/` timestamp)

# One-liner setup

git init  # if not already
