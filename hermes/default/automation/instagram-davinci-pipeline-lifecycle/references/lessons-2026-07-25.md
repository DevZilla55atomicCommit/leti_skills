## Key Fixes & Patterns Established

### 1. Auto-Compression Failure Root Cause
**Problem:** Session grew to 95% context (1,000+ messages) without auto-compression triggering.

**Root Cause:** NVIDIA provider pointing to local Ollama base_url (`http://127.0.0.1:11434/v1`) but model `nvidia/nemotron-mini-4b-instruct` only exists on NVIDIA API endpoint.

**Fix:** Remove `base_url` or set to `https://integrate.api.nvidia.com/v1` in config.yaml.

```yaml
# ~/.hermes/config.yaml
auxiliary:
  compression:
    provider: nvidia
    model: nvidia/nemotron-mini-4b-instruct
    base_url: https://integrate.api.nvidia.com/v1  # NOT local Ollama
    enabled: true
    threshold: 0.7
```

**Verification:** `nvidia/nemotron-mini-4b-instruct` IS available on NVIDIA API (confirmed via `/v1/models`).
