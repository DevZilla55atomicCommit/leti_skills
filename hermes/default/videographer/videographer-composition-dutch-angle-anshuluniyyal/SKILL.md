# Dutch Angle (Canted Frame) — Composition Skill

## 🏗️ Core Principles

| Principle | Execution |
|-----------|-----------|
| **Match Angle to Terrain** | Canted frame aligns with slope angle |
| **Purposeful, Not Arbitrary** | Tilt has diegetic justification (slope) |
| **Center Anchor** | Subject on vertical center despite tilt |
| **Diagonal Energy** | Ridge line = dynamic diagonal |
| **Horizon as Story** | Tilted horizon = instability, journey, unease |

---

## 📸 Shot Recipe (Reproducible)

### Pre-Production
- [ ] Location: Steep ridge, scree slope, dunes — any strong diagonal landform
- [ ] **Scout for angle:** Find where slope angle = desired cant (15-30° typical)
- [ ] Time: Golden hour for side-light texture on slope
- [ ] Lens: 24-35mm (wide enough for context, not so wide distortion dominates)

### Production
- [ ] **Level base, then tilt** — start level on tripod, rotate head to match slope
- [ ] **Use grid overlay** — confirm tilt angle matches terrain (not arbitrary)
- [ ] **Center subject** on vertical axis — anchor for tilted frame
- [ ] **Focus** on subject plane; deep DOF (f/8-f/11) for layers
- [ ] **Bracket exposure** — tilted frame = uneven sky/ground exposure

### Post-Production (DaVinci Resolve)

```
NODE 01 — Primary Balance
    │  • Lift/Gain/Gamma: balance tilted exposure
    │  • Temp: +10 (golden hour warmth)
    ▼
NODE 02 — Horizon Correction (Optional)
    │  • Transform: Rotate -X° to level horizon (ONLY if delivering level version)
    │  • Keep original node for canted deliverable
    ▼
NODE 03 — Contrast & Texture (Serial)
    │  • Contrast: +15 | Pivot: 40
    │  • Custom Curve: S for density
    ▼
NODE 04 — Color Separation (Parallel)
    │  • Hue vs Hue: Rocks → Warm (+15) | Sky → Cool (-10)
    │  • Hue vs Sat: Subject robes → +20
    ▼
NODE 05 — Vignette (Follows Tilt)
    │  • Power Window: large oval, rotated to match frame tilt
    │  • Feather: 0.9 | Gain: -0.1
    ▼
OUTPUT
```

## ⚠️ Common Pitfalls & Fixes

| Problem | Root Cause | Solution |
|---------|------------|----------|
| "Feels like a mistake" | Tilt doesn't match terrain | Only cant when diegetic reason exists |
| Viewer gets nauseous | Excessive tilt (>30°) or rapid cuts | Max 20-25°; hold shot longer; center anchor |
| Subject looks like falling | Subject not centered vertically | Place subject on vertical center line |
| Horizon distracts | Tilt too subtle (looks accidental) | Commit: 15° minimum or go level |
| Exposure mismatch | Sky bright / ground dark in tilt | Bracket; grade sky/ground separately (parallel nodes) |

---

## ✅ Verification Checklist

- [ ] Tilt angle **matches a visible slope/line** in the scene
- [ ] Subject **anchored on vertical center** of frame
- [ ] Horizon line **clearly diagonal** (not subtle)
- [ ] Exposure balanced for **both sky and ground** (or graded separately)
- [ ] Shot **holds long enough** (3-5 sec) for viewer to orient
- [ ] Dutch angle **serves story** — not just "looks cool"
