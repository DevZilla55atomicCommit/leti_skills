Today, we’re talking about my favorite intro to use at the moment. 

That intro is what i like to call a Quick Shutter Intro. 

I think it looks sick and it’s also very engaging as it moves quickly, sets the tone for the video and what the viewer is about to see and sounds good using a quick shutter sound effect to play off the motion. 

This effect is also so easy to achieve. This is obviously a Premiere Pro tutorial as that is what I use to edit but I would imagine you would be able to create a similar effect using key frames in DaVinci, CapCut or whatever you use to edit. 

Copy what I do in this video and you should achieve a very similar effect. You can also play around with the values in the directional blur effect to make it more or less dramatic. I like to keep it low enough that you can still see what is going on, but fast enough so that there is some motion blur.
