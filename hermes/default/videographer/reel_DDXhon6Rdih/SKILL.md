## 🎬 Frame Counting Workflow

### Pre-Production (Planning)
```
1. Script/Outline → Mark emotional beats
2. Assign target frame counts per beat:
   - Hook/Opener: 12-18 frames (0.5-0.75s @ 24fps)
   - Build: 24-36 frames per shot
   - Climax: 12-24 frames (accelerated)
   - Resolution: 48-72 frames (linger)
3. Create "Frame Map" — spreadsheet/timeline sketch
```

### Production (Shooting for the Edit)
- [ ] Shoot with handles (3-5 sec pre/post roll) for frame flexibility
- [ ] Maintain consistent frame rate (don't mix 24/30/60 without plan)
- [ ] Use slate/markers for sync points

### Post-Production (DaVinci Resolve / NLE)
```
Timeline Setup:
  Project Settings → Timeline Frame Rate: 24 (or target)
  Timeline → Show Frame Numbers (not just timecode)

Editing Process:
  1. Assembly → rough cut to Frame Map
  2. Fine Cut → razor at exact frame boundaries
  3. Micro-Timing → nudge ±1-2 frames for "feel"
  4. Review → watch at 2x, 0.5x, frame-by-frame
```

**DaVinci Resolve Shortcuts:**
- `,` / `.` — nudge selected clip ±1 frame
- `Shift+,` / `Shift+.` — nudge ±10 frames
- `Alt+[` / `Alt+]` — trim edit point ±1 frame
- `Ctrl+Shift+F` — toggle frame numbers on timeline ruler
