## 🎯 Technique Summary

When a cut looks obvious due to lighting/color differences between clips, two techniques blend them seamlessly: **speed ramping** (speed up the end of clip A and beginning of clip B where the cut happens) + **cross-dissolve on overlapping layers** (place clips on separate tracks, overlap them, add dissolve/fade). The creator demonstrates both combined, transforming a jarring cut into an invisible transition.

## 🏗️ Core Principles

| Principle | Description |
|-----------|-------------|
| **Speed Ramp Masking** | Accelerating through the cut point reduces perceptual dwell time on the discontinuity |
| **Layer-Based Cross-Dissolve** | Overlapping clips on separate tracks allows true additive blending (vs. single-track dissolve) |
| **Combined Approach** | Speed ramp + dissolve > either alone; ramp hides temporal discontinuity, dissolve hides spatial/color discontinuity |

## ⚠️ Common Pitfalls & Fixes

| Problem | Root Cause | Solution |
|---------|------------|----------|
| Ramp looks "stuttery" | Frame blending off / insufficient frames | Enable Optical Flow / Speed Warp in Retime; shoot higher fps (60fps+) for handles |
| Dissolve shows "ghosting" | Clips not aligned / motion mismatch | Stabilize both clips first; ensure subject position continuity |
| Color still mismatched after dissolve | No primary balance before blend | Grade both clips to neutral match (Node 02) BEFORE applying dissolve |
| Ramp too abrupt | Linear speed change | Use ease-in/ease-out curves (bezier) on Retime Curve |

## ✅ Verification Checklist

- [ ] Speed ramp applied to both clips (outgoing acceleration + incoming deceleration)
- [ ] Cross-dissolve on overlapping tracks (not single-track transition)
- [ ] Primary color balance matched before blend
- [ ] Optical Flow/Speed Warp enabled for smooth motion
- [ ] Handles sufficient for overlap duration (15-30 frames minimum)
- [ ] Result reviewed at full speed + frame-by-frame
