## 🎯 Technique Summary

**Framing is not just composition — it's narrative control.** This reel (Day 6 of 30 framing series) distills framing into four essential functions: (1) **Directs Audience Attention** — guides the eye to what matters, (2) **Shapes the Narrative** — framing choices emphasize emotion/relationships/context, (3) **Creates Visual Aesthetics** — thoughtful composition elevates mood/style/memorability, (4) **Establishes Perspective** — determines how audience perceives action/characters/environment and their emotional connection.

## 🏗️ Core Principles

| Principle | Description | Practical Application |
|-----------|-------------|----------------------|
| **1. Directs Audience Attention** | Frame isolates subject; negative space, leading lines, rule of thirds guide the eye | Place subject on power points; use foreground elements as frames within frame |
| **2. Shapes the Narrative** | Close-up = intimacy/emotion; wide = context/isolation; angle = power dynamic | Choose frame size/angle to serve story beat, not just "coverage" |
| **3. Creates Visual Aesthetics** | Balance, symmetry, color harmony, depth layers create mood/style | Plan color palette in frame; use depth (FG/MG/BG) for 3D feel in 2D |
| **4. Establishes Perspective** | POV shots = subjectivity; high/low angle = power/vulnerability | Camera position = audience's psychological position |

## 🎬 Framing Decision Framework

### Pre-Production: Frame Planning
```
For each scene, define:
  □ Primary subject & emotional intent
  □ Frame size (ECU/CU/MS/WS/ELS) — why this size?
  □ Camera angle (eye-level/high/low/dutch) — why this angle?
  □ Composition rule (thirds/golden ratio/symmetry/center) — why?
  □ Depth strategy (layers: foreground/midground/background)
  □ Movement (static/pan/tilt/dolly/handheld) — motivated or not?
```

### Production: On-Set Execution
```
Before each take:
  [ ] Frame checked on monitor (not just viewfinder)
  [ ] Edges scanned for intrusions (booms, stands, crew)
  [ ] Headroom / lookroom / lead room verified
  [ ] Background continuity with adjacent shots
  [ ] Exposure/Focus confirmed on subject's eyes
```

### Post-Production: Frame Refinement (DaVinci Resolve)
```
Node Structure for Framing Enhancement:
Node 01 — CST (Log → DWG)
Node 02 — Reframing (Transform: Pan/Tilt/Zoom for micro-adjust)
Node 03 — Vignette (subtle, guides eye to center)
Node 04 — Aspect Ratio Matte (letterbox/pillarbox for delivery)
Node 05 — Creative Grade
Node 06 — Output CST
```

## 📐 Composition Quick Reference

| Frame Size | Emotional Effect | Typical Use |
|------------|------------------|-------------|
| **ECU** (Extreme Close-Up) | Intensity, abstraction, detail | Eyes, texture, critical object |
| **CU** (Close-Up) | Intimacy, emotion, reaction | Dialogue, performance |
| **MCU** (Medium Close-Up) | Personal connection | Two-shot dialogue |
| **MS** (Medium Shot) | Body language, gesture | Action + context |
| **WS** (Wide Shot) | Environment, isolation, scale | Establishing, master |
| **ELS** (Extreme Long Shot) | Grandeur, insignificance | Landscape, epic scope |

| Angle | Psychological Effect |
|-------|---------------------|
| **Eye-Level** | Neutral, equality, realism |
| **Low Angle** | Power, dominance, heroism |
| **High Angle** | Vulnerability, weakness, oversight |
| **Dutch/Canted** | Unease, tension, disorientation |
| **Overhead/Top-Down** | Omniscience, pattern, detachment |
