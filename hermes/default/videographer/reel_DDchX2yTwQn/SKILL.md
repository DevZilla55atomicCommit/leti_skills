## 🎬 Step-by-Step Workflow

### 1. Data Export (from Instagram)
```
Instagram App → Profile → Menu (☰) → Insights → 
  • Overview → "Download Data" (JSON/CSV)
  • Or: Meta Business Suite → Insights → Export
Key metrics to capture:
  - Follower growth (daily/weekly)
  - Reach / Impressions per post
  - Engagement rate (likes + comments + saves + shares / reach)
  - Best/worst performing posts (by type: Reel, Carousel, Story)
  - Audience demographics (age, gender, location, active hours)
  - Profile visits, website clicks, email clicks
```

### 2. Data Preparation
```
Clean the export:
  - Remove PII (keep only metrics)
  - Aggregate by post type (Reel vs Carousel vs Story)
  - Calculate rolling 7/30-day averages
  - Flag outliers (viral posts, flops)
  - Format as Markdown table or CSV for ChatGPT
```

### 3. ChatGPT Prompt Template
```
You are an Instagram growth strategist. Analyze this account data and provide:

1. **Health Score** (1-10) with justification
2. **Top 3 Strengths** (what's working)
3. **Top 3 Weaknesses** (what's failing)
4. **Content Strategy Recommendations**:
   - Optimal post frequency
   - Best content types/formats
   - Ideal posting times (from audience active hours)
   - Caption/hooks strategy
5. **Growth Tactics** (3 specific, measurable actions for next 30 days)
6. **Competitive Benchmarking** (if competitor data provided)

Data:
[PASTE CLEANED DATA HERE]
```

### 4. Implementation & Tracking
```
Week 1: Implement posting schedule + content mix changes
Week 2: A/B test hook styles (question vs statement vs story)
Week 3: Engage with top 50 engagers daily (comments/DMs)
Week 4: Re-run audit → compare deltas → iterate
```
