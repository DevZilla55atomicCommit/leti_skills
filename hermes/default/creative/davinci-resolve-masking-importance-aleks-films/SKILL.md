- **Focus:** Masking for selective color grading / exposure control

## Key Concept: Masking Importance

Masking (Power Windows, Magic Mask, Qualifier) allows you to:
1. **Isolate subjects** from backgrounds for independent grading
2. **Fix exposure mismatches** between subject and environment
3. **Create depth** by grading foreground/background differently
4. **Track moving subjects** (motorcycles, people, vehicles) for consistent looks

## Workflow Implication

For fast-moving subjects (bikes, cars, action):
- Use **Power Windows with tracking** for geometric shapes
- Use **Magic Mask (Studio)** for organic shapes with Neural Engine
- Combine with **Qualifier** for color-based isolation
- **Keyframe** or **track** masks for motion
