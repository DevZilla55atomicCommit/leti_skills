# Complementary Color Scheme — @martinwikestad

Color theory breakdown of complementary color schemes for impactful, balanced grading. Based on Lightroom workflow but directly transferable to DaVinci Resolve.

## When to Use
- Creating bold, balanced color grades
- Understanding why teal/orange works
- Exploring alternative complementary pairs

## Prerequisites
- Basic color theory knowledge
- DaVinci Resolve or Lightroom

## Quick Reference

| Complementary Pair | Hue Separation | Use Case |
|--------------------|----------------|----------|
| **Blue + Orange** | 180° | Classic cinematic, skin tones |
| **Red + Green** | 180° | Holiday, nature, stylized |
| **Purple + Yellow** | 180° | Creative, fashion, surreal |

---

## Lightroom Workflow (Transferable to Resolve)

| Step | Lightroom Tool | Resolve Equivalent |
|------|----------------|-------------------|
| 1. Shift base tones | Calibration + HSL Hue | Color Wheels / Curves / Color Warper |
| 2. Boost saturation | Saturation slider | Color Wheels Sat / Color Warper |
| 3. Guide attention | Luminance | Curves / Color Wheels Gain/Lift |
| 4. Clean separation | Masking | Qualifier / Power Window / Magic Mask |

---

## Key Principles

- **180° apart on color wheel** = maximum contrast + harmony
- **Balance over saturation** — don't overdo Clarity
- **Grain unifies** the look
- **Masking prevents bleed** between complementary hues

---

## Verification Checklist

- [ ] Identify complementary pair for project
- [ ] Shift base tones toward pair (Calibration/Hue)
- [ ] Boost both colors' saturation
- [ ] Adjust luminance for focal point
- [ ] Mask to prevent color bleed
