# Color Wheels vs Log Wheels — @creatorsergeant

Breakdown of the differences between Color Wheels (Primary) and Log Wheels in DaVinci Resolve.

## When to Use
- Understanding when to use each wheel type
- Choosing the right tool for the job
- Beginner color grading education

## Prerequisites
- DaVinci Resolve (Free or Studio)
- Color Page access

## Quick Reference

| Wheel Type | Operation | Best For |
|------------|-----------|----------|
| **Color Wheels (Primary)** | Display-referred / Perceptual | Creative grading, skin tones, artistic intent |
| **Log Wheels** | Scene-referred / Linear-ish | Technical calibration, exposure, true blacks |

---

## Core Difference

| Aspect | Color Wheels (Primary) | Log Wheels |
|--------|----------------------|------------|
| **Color Space** | Display-referred (gamma-encoded) | Scene-referred (linear-ish) |
| **Operation** | Perceptual / Lift/Gamma/Gain | Printer-light style / Exposure-based |
| **Shadows (Lift)** | Crushes/lifts display blacks | Adjusts scene exposure at bottom |
| **Midtones (Gamma)** | Perceptual contrast pivot | Linear gain around middle gray |
| **Highlights (Gain)** | Display white scaling | Scene highlight scaling |

---

## When to Use Which

| Scenario | Recommended |
|----------|-------------|
| Creative look / skin tones | Color Wheels (Primary) |
| Matching shots technically | Log Wheels |
| Setting true blacks | Log Wheels (Lift) |
| Artistic contrast | Color Wheels (Gamma) |
| HDR grading | Log Wheels / HDR Wheels |
