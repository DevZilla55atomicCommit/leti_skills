# Color Shift / Color Change — DaVinci Resolve (@davinciresolved)

Technique for changing specific colors in footage using Qualifier and Hue vs Hue curves.

## When to Use
- Changing clothing colors
- Color replacement (e.g., red car → blue)
- Selective hue shifting
- Skin tone protection during color changes

## Prerequisites
- DaVinci Resolve (Free or Studio)
- Basic Qualifier understanding

## Quick Reference

| Tool | Purpose |
|------|---------|
| **Qualifier** | Select target color range (H/S/L) |
| **Hue vs Hue Curve** | Shift selected hue to new hue |
| **Hue vs Sat** | Desaturate/protect adjacent colors |
| **Hue vs Lum** | Adjust brightness of shifted color |
