## Overview

After the Instagram Reels pipeline extracts frames and creates vault notes, Phase 2 adds **color science metadata** from DaVinci Resolve via MCP. This provides:

- Log format detection (S-Log3, Apple Log 2, etc.)
- Color space identification (S-Gamut3.Cine, etc.)
- Exposure analysis (IRE levels, stops over/under)
- Suggested CST input/output transforms
- LUT recommendations (Kodak 2383, Fujifilm, etc.)

---

## Pipeline Integration Point

```python
# In process_reels.py v2, after vault note creation:
async def append_davinci_color_analysis(reel_code, mp4_path, note_path):
    \"\"\"Import reel to DaVinci, analyze color, append to vault note.\"\"\"
    
    # 1. Import MP4 to Media Pool
    clip_id = mcp.media_storage.import_to_pool([mp4_path])
    
    # 2. Vision analysis (no transcription needed)
    vision = mcp.media_analysis.analyze_clip(
        clip_id=clip_id,
        vision=True,
        transcription=False
    )
    
    # 3. Grade evidence base (node graph + color groups + coverage)
    evidence = mcp.timeline_item_color.grade_evidence_base(
        track_type="video", track_index=1, item_index=0,
        min_source_trust="high"
    )
    
    # 4. Parse color science metadata
    color_data = extract_color_science(vision, evidence)
    
    # 5. Append to vault note
    append_davinci_section(note_path, color_data)
```

## MCP Calls Required

| Step | MCP Tool | Action | Params |
|------|----------|--------|--------|
| 1 | `media_storage` | `import_to_pool` | `{"items": ["/path/to/reel.mp4"]}` |
| 2 | `media_analysis` | `analyze_clip` | `{"clip_id": "...", "vision": true, "transcription": false}` |
| 3 | `timeline_item_color` | `grade_evidence_base` | `{"track_type": "video", "track_index": 1, "item_index": 0, "min_source_trust": "high"}` |
| 4 | `media_pool` | `delete_clips` | `{"clip_ids": ["..."]}` (cleanup) |

---

## Error Handling

| Failure Mode | Fallback |
|--------------|----------|
| Resolve not running | Auto-launch (30-60s delay), retry |
| Clip import fails | Skip analysis, note "DaVinci unavailable" in vault |
| Vision analysis fails | Use `grade_evidence_base` only (node graph metadata) |
| Clip not on timeline | Add to timeline first via `timeline.append_to_timeline` |
