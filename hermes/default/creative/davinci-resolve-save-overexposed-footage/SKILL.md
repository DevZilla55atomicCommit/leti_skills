# Save Overexposed Footage — DaVinci Resolve (@davinciresolved)

Technique for recovering overexposed footage using DaVinci Resolve tools and blend modes.

## When to Use
- Overexposed highlights in footage
- Blown-out skies/skin
- Emergency recovery workflows

## Prerequisites
- DaVinci Resolve (Free or Studio)
- Footage with highlight detail still present (not clipped to pure white)

## Quick Reference

| Method | Tool | Best For |
|--------|------|----------|
| **Gain Reduction** | Color Wheels / Offset | Mild overexposure |
| **Highlight Recovery** | Highlight Recovery (Studio) / Custom | Moderate clipping |
| **Multiply Blend** | Edit Page: Clip on top, Multiply mode | Quick composite fix |
| **Power Window** | Qualifier + Power Window | Localized overexposure |
