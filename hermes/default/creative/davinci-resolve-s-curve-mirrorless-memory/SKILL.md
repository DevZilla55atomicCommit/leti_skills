# S-Curve in DaVinci Resolve — @mirrorless_memory_

Technique for using S-Curve in Custom Curves for cinematic contrast and film-like rolloff.

## When to Use
- Adding film-like contrast
- Highlight rolloff / shadow lift
- Cinematic look development

## Prerequisites
- DaVinci Resolve (Free or Studio)
- Color Page access

## Quick Reference

| Curve Point | Action | Effect |
|-------------|--------|--------|
| **Bottom-left (shadows)** | Drag UP | Lift blacks, reduce contrast |
| **Lower-mid** | Drag DOWN | Deepen shadows |
| **Middle (midtones)** | Anchor | Preserve middle gray |
| **Upper-mid** | Drag UP | Brighten midtones |
| **Top-right (highlights)** | Drag DOWN | Roll off highlights |
