# Low Contrast Dreamy Look — @caleboshi

Quick shortcut for creating a low contrast, dreamy/ethereal look in DaVinci Resolve using Curves.

## When to Use
- Dreamy, ethereal aesthetic
- Low contrast film look
- Quick grading shortcut

## Prerequisites
- DaVinci Resolve (Free or Studio)
- Color Page access

## Quick Reference

| Tool | Action | Channel |
|------|--------|---------|
| **Custom Curves** | Lift blacks, lower whites | Y (Luma) only for contrast, YRGB for desat |
| **Isolate Y Channel** | Retain saturation | Key tip from caption |

---

## Technique (from Caption)

1. **Custom Curves** node
2. **Lift bottom-left point** (raise blacks)
3. **Lower top-right point** (lower whites)
4. **CRITICAL:** Isolate **"Y" channel only** to retain saturation
   - If YRGB all on → desaturates as contrast drops
   - Y only → keeps color intensity
