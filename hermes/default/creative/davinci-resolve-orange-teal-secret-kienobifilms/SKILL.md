# Color Grading Secret: Orange & Teal — @kienobifilms

Complete breakdown of orange & teal look using Primary and Log Color Wheels — foundational technique for cinematic contrast.

## When to Use
- Creating cinematic orange & teal look
- Understanding Primary vs Log wheel differences
- Skin tone emphasis with contrast

## Prerequisites
- DaVinci Resolve (Free or Studio)
- Color Page access

## Quick Reference

| Wheel | Target | Action |
|-------|--------|--------|
| **Primary — Midtones (Gamma)** | Skin tones | Push toward orange/yellow |
| **Primary — Shadows (Lift)** | Contrast base | Push toward blue/teal |
| **Log — Shadows** | True blacks | Align RGB just above 0 |

---

## Core Technique

### Primary Wheels (Creative)
```
Midtones (Gamma): → Orange/Yellow (skin emphasis)
Shadows (Lift):   → Blue/Teal     (contrast base)
Highlights (Gain): Usually neutral or slight warmth
```

### Log Wheels (Technical/Calibration)
```
Shadows (Lift): Align R/G/B traces just above 0 on Parade
→ Ensures true blacks, no color cast in shadows
```
