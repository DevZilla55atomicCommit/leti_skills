# Footage Pop — @davinciresolved

Quick technique for adding instant contrast, saturation, and dimensionality to flat footage using Primary Wheels.

## When to Use
- Fast turnaround grades
- Starting base grade for flat log footage
- Quick client preview looks
- Social media content

## Prerequisites
- DaVinci Resolve (Free or Studio) 18+
- Color Page access

## Quick Reference

| Parameter | Range | Purpose |
|-----------|-------|---------|
| **Lift** | -0.05 to -0.15 | Deepen shadows |
| **Gamma** | 0.95–1.05 | Slight midtone adjust |
| **Gain** | +0.05 to +0.15 | Lift highlights |
| **Contrast** | +15 to +25 | Core pop control |
| **Pivot** | 0.40–0.50 | Protect midtones |
| **Saturation** | +10 to +15 | Color vitality |

---

## Technique (from Caption)

Quick pop using Lift/Gamma/Gain + Contrast/Pivot + Saturation boost.
