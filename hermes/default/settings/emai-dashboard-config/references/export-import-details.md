# Export and Import EMAI Dashboard Settings

## Export

1. Open **Settings** → **Community Plugins** → **EMAI Dashboard**.
2. Click the **gear** icon (⚙️) to open Actions.
3. Select **Export Config**. This downloads `emai-dashboard-config.json`.

## Import

1. Open **Settings** → **Community Plugins** → **EMAI Dashboard**.
2. Click the **gear** icon (⚙️) again.
3. Choose **Import Config** and select the previously exported JSON file.

## Tips

- Keep backups in your vault for easy restore.
- Validate JSON after export if you plan to edit manually.
