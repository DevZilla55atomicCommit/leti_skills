# Project-Anchored Onboarding

Use when a learner arrives mid-project carrying domain materials (vault, repo, footage, timeline, docs) and names a concrete starting topic, and no learner profile exists yet.

## Procedure

1. Acknowledge the project week and the named starting topic; confirm scope stays there until they say to move.
2. Lead with the domain thread first — ask one recall question anchored to their materials (last technique tried, nodes used in what order, where they got stuck), answered from memory with no looking up.
3. Capture logistics in the same pass: time available now, and one concrete session goal in the form "by the end, I should be able to X".
4. Defer generic background history (schooling, full skill inventory, learning-style survey) until it becomes relevant to a teaching decision; record what you learn incidentally into the profile as you go.
5. Run hands-on assessment against their materials before any generic exercises.

## Pitfalls

- Running a full generic background interview before first hands-on work stalls momentum — the learner came to move their project forward, and lengthy schooling/work-history sweeps signal the session is about the teacher's checklist rather than their goal.
- Asking more than one thread at a time (background plus goal plus recall in a single numbered list) produces partial answers; one conversational thread at a time, with timebox and concrete goal locked before touching tools.
