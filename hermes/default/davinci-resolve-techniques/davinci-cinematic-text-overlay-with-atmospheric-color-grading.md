# Cinematic Text Overlay with Atmospheric Color Grading

**Source:** Instagram Reel `DADheFIhtiB` (Ideas_for_Shooting_Videos)  
**Page:** Fusion | **Graph:** serial | **Difficulty:** intermediate

![Cinematic Text Overlay with Atmospheric Color Grading](DADheFIhtiB.gif)

## Node Graph Structure

- MediaIn
- Text+
- Merge
- ColorCorrect

## Parameters

- **Text**: FARCE ISLANDS
- **Opacity**: 0.8
- **Rotation**: 90 degrees
- **Contrast**: High
- **Saturation**: Low

## Steps to Reproduce in DaVinci Resolve

1. Import footage and switch to Fusion page.
2. Add a Text+ node and type FARCE ISLANDS.
3. Rotate the text layer 90 degrees to orient it vertically.
4. Apply a texture map or a mask to the text node to create the distressed look.
5. Merge the text layer over the background footage using a Merge node.
6. Go back to the Color page to apply a teal-and-orange desaturated LUT or manual grade.
