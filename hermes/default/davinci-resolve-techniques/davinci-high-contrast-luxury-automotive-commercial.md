# High-Contrast Luxury Automotive Commercial

**Source:** Instagram Reel `C9VIVruh1vU` (Ideas_for_Shooting_Videos)  
**Page:** Color | **Graph:** serial | **Difficulty:** intermediate

![High-Contrast Luxury Automotive Commercial](C9VIVruh1vU.gif)

## Node Graph Structure

- Primary Balance
- Curves Contrast
- Color Wheels
- Qualifier / Glow

## Parameters

- **contrast**: 1.45
- **saturation**: 0.65
- **pivot**: 0.55
- **blacks_lift**: -0.02
- **highlights_gain**: +0.05

## Steps to Reproduce in DaVinci Resolve

1. Adjust exposure to maintain deep blacks without losing detail in the car paint.
2. Use the Curves tool to create a subtle S-curve for punchy highlights and deep shadows.
3. Apply a slight desaturation to the overall image to achieve a sophisticated expensive look.
4. Use a Qualifier to select only the red taillights and increase saturation and add a slight Glow effect to make them pop.
5. Add a subtle vignette to draw focus toward the center of the vehicle.
6. Ensure the sky remains clean and blue without clipping.
