# Radial Zoom / Zoom Warp Effect

## Node Graph Structure

## Parameters

- **Dynamic Zoom**: Enabled
- **Zooming**: In/Out
- **Ease Speed**: Keyframe-adjusted

## Steps to Reproduce in DaVinci Resolve

1. Select the clip on the timeline
2. Open the Inspector and navigate to the Zoom tab
3. Enable the Dynamic Zoom toggle
4. Set a keyframe at the start of the clip
5. Move the playhead to the end of the clip
6. Adjust the 'Green' and 'Red' bounding boxes to create the zoom path
7. Use the Keyframe Editor to ease curves for smooth motion
