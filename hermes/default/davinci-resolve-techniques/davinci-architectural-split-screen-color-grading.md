# Architectural Split-Screen Color Grading

**Source:** Instagram Reel `C4yvrhEpXuk` (Gimbal_Moves)  
**Page:** Color | **Graph:** serial | **Difficulty:** beginner

![Architectural Split-Screen Color Grading](C4yvrhEpXuk.gif)

## Node Graph Structure

- Primary Correction
- Color Wheels
- Power Window
- Adjustment Layer

## Parameters

- **Contrast**: +0.2
- **Saturation**: +1.2
- **Midtone Tint**: Warm/Golden
- **Shadows**: Cool/Teal

## Steps to Reproduce in DaVinci Resolve

1. Import four separate architectural clips into the timeline.
2. Place each clip on a separate track (V1-V4).
3. Use the Crop tool in the Inspector to crop each clip to a horizontal quarter of the frame.
4. Apply a global color grade using a serial node structure to unify the color palette.
5. Use Power Windows to enhance highlights on marble surfaces and water reflections.
6. Add a slight vignette to draw focus to the center of each frame.
