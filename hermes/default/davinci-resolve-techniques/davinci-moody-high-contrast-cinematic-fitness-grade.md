# Moody High-Contrast Cinematic Fitness Grade

**Source:** Instagram Reel `C82Mt4HKWuB` (Ideas_for_Shooting_Videos)  
**Page:** Color | **Graph:** serial | **Difficulty:** intermediate

![Moody High-Contrast Cinematic Fitness Grade](C82Mt4HKWuB.gif)

## Node Graph Structure

- Primary Balance
- Curves Contrast
- Color Wheels Split
- Halation

## Parameters

- **contrast**: 1.45
- **saturation**: 0.75
- **lift_tint**: Teal/Blue
- **midtonetint**: Warm/Orange
- **pivot**: 0.5

## Steps to Reproduce in DaVinci Resolve

1. Apply a primary grade to balance exposure, slightly pulling down the highlights.
2. Use the Curves tool to create a subtle S-curve for deep contrast and crushed blacks.
3. In the Color Wheels node, push a subtle blue tint into the shadows (Lifts) and a warm tint into the midtones.
4. Reduce the overall saturation to maintain a moody aesthetic.
5. Add a slight Glow or Halation effect in the Fusion node or via a layer node to soften the highlights on the metallic equipment.
