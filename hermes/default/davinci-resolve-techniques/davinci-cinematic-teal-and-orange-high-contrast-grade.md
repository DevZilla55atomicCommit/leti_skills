# Cinematic Teal and Orange High-Contrast Grade

**Source:** Instagram Reel `C87SAwdKjut` (Ideas_for_Shooting_Videos)  
**Page:** Color | **Graph:** serial | **Difficulty:** intermediate

![Cinematic Teal and Orange High-Contrast Grade](C87SAwdKjut.gif)

## Node Graph Structure

- Primary Balance
- Curves
- Color Wheels
- Power Window

## Parameters

- **contrast**: 1.2
- **saturation**: 450
- **shadow_tint**: Teal/Cyan
- **highlight_tint**: Orange/Warm
- **lift_offset**: -0.02

## Steps to Reproduce in DaVinci Resolve

1. Adjust the Lift to deepen the shadows and add a slight cyan tint.
2. Use the Curves tool to create a subtle S-curve for increased contrast.
3. Apply a Color Wheels adjustment to push highlights toward orange/yellow.
4. Use a Power Window to isolate the subject face and increase the warm rim light exposure.
5. Increase saturation globally while keeping skin tones natural via the Qualifier or Hue curves.
