# Cinematic Bokeh & Teal/Orange Contrast

**Source:** Instagram Reel `C9wiDzHyEvd` (Ideas_for_Shooting_Videos)  
**Page:** Color | **Graph:** serial | **Difficulty:** intermediate

![Cinematic Bokeh & Teal/Orange Contrast](C9wiDzHyEvd.gif)

## Node Graph Structure

- Exposure Correction
- Primary Balance
- Split Tone Overlay
- Glow/Halation
- Vignette

## Parameters

- **Contrast**: 0.4
- **Shadows**: Lifted
- **Midtones Tint**: Teal/Cyan
- **Highlights Tint**: Warm Orange/Yellow
- **Glow Radius**: Soft/High Diffusion

## Steps to Reproduce in DaVinci Resolve

1. Lift the blacks using the Curves tool to create a faded, cinematic look.
2. Use a Hue Qualifier to desaturate the background elements while keeping skin tones vibrant.
3. Apply a subtle teal tint to the shadows using the Split Tone tool.
4. Apply a warm orange tint to the highlights to emphasize the light source.
5. Add a Glow node with a high radius and low threshold to create the soft 'dreamy' effect around the light orb.
6. Add a slight vignette to draw focus to the center-weighted light source.
