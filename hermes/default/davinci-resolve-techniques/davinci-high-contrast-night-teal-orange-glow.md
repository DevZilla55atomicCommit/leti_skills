# High-Contrast Night Teal & Orange Glow

**Source:** Instagram Reel `C5eEIvUuO28` (Cinematic)  
**Page:** Color | **Graph:** serial | **Difficulty:** intermediate

![High-Contrast Night Teal & Orange Glow](C5eEIvUuO28.gif)

## Node Graph Structure

- Exposure
- Primary Balance
- Color Wheels
- Glow
- Halation

## Parameters

- **contrast**: 1.4
- **saturation**: 1.2
- **lift_tint**: Teal
- **highlight_tint**: Warm Orange/Yellow
- **glow_threshold**: 0.45

## Steps to Reproduce in DaVinci Resolve

1. Adjust Exposure to deepen the blacks and increase contrast for a night-time look.
2. Apply a teal tint to the shadows and a warm/orange tint to the highlights using Color Wheels.
3. Use the Glow node with a soft falloff and high threshold to simulate the streetlamp bloom
4. Increase saturation slightly to make the yellow text and lights pop against the dark.
5. Add a slight Halation effect to the brightest light sources to mimic film light bleed.
