# Camera Stabilization

**Source:** Instagram Reel `CxKvlvyLOzl` (Gimbal_Moves)  
**Page:** Color | **Graph:** serial | **Difficulty:** beginner

![Camera Stabilization](CxKvlvyLOzl.gif)

## Node Graph Structure

- Stabilizer Node

## Parameters

- **Stabilization Mode**: Camera
- **Smoothing**: 50.0
- **Zoom**: Auto

## Steps to Reproduce in DaVinci Resolve

1. Select the clip on the Color page
2. Open the Inspector tab
3. Navigate to the Stabilization section
4. Set Mode to 'Camera'
5. Click 'Stabilize'
6. Adjust Smoothing value to remove jitter without excessive cropping
