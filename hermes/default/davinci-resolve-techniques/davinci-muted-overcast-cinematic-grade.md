# Muted Overcast Cinematic Grade

**Source:** Instagram Reel `C6yZN1MSuOL` (Ideas_for_Shooting_Videos)  
**Page:** Color | **Graph:** serial | **Difficulty:** beginner

![Muted Overcast Cinematic Grade](C6yZN1MSuOL.gif)

## Node Graph Structure

- Primary Color Correction
- Curves
- Color Wheels
- Power Windows

## Parameters

- **lift**: +0.02
- **contrast**: 0.85
- **_saturation**: 0.35
- **temp**: -500
- **tint**: +5
- **shadow_tint**: Cyan/Blue

## Steps to Reproduce in DaVinci Resolve

1. Lift the black point in the Curves tool slightly to fade the shadows, turning true black into a dark grey.
2. Reduce the overall saturation to achieve a desaturated, moody look.
3. Shift the Temperature slider toward blue (cool) to enhance the cold, overcast feel.
4. Use the Color Wheels to add a subtle teal or blue tint to the shadows.
5. Apply a soft Power Window around the clock face to slightly increase exposure and clarity, making it pop against the muted background.
