# High-Key Winter Cinematic Contrast

**Source:** Instagram Reel `C_Sg2I9v788` (Ideas_for_Shooting_Videos)  
**Page:** Color | **Graph:** serial | **Difficulty:** intermediate

![High-Key Winter Cinematic Contrast](C_Sg2I9v788.gif)

## Node Graph Structure

- Exposure
- Primary Balance
- Color Wheels
- HSL Curves
- Power Window

## Parameters

- **Lift**: -0.02
- **Gain**: +0.15
- **Gamma**: Teal tint
- **Midtones**: Warm/Orange
- **Saturation**: 0.85

## Steps to Reproduce in DaVinci Resolve

1. Increase exposure to create a high-key snowy look.
2. Lift the shadows slightly and add a subtle blue/teal tint using the Lift wheel.
3. Use the Gamma wheel to add a warm orange/yellow tint to skin tones.
4. Use HSL Curves to desaturate greens and blues while keeping oranges vibrant.
5. Apply a soft Power Window on the face to slightly increase exposure and sharpness.
6. Add a slight Glow effect in the Fusion tab or via a node to soften the highlights.
