# Soft Luxury Real Estate Grade

**Source:** Instagram Reel `C3xoLWSARhz` (Gimbal_Moves)  
**Page:** Color | **Graph:** serial | **Difficulty:** intermediate

![Soft Luxury Real Estate Grade](C3xoLWSARhz.gif)

## Node Graph Structure

- Primary Correction
- Color Wheels
- Power Windows
- Soft Glow

## Parameters

- **Contrast**: +0.05
- **Saturation**: -10
- **Midtones**: +5
- **Shadows**: -10
- **Tint**: Warm (Yellow/Orange shift in midtones)

## Steps to Reproduce in DaVinci Resolve

1. Import footage and go to the Color page.
2. Use Primary Wheels to balance white balance (ensure whites look truly neutral).
3. Increase contrast slightly while softening highlights to create a creamy look.
4. Lower saturation to achieve a sophisticated, desaturated palette.
5. Apply a Power Window to windows to slightly increase exposure without blowing out details.
6. Add a very subtle warm tint to the midtones to make the interior feel inviting.
