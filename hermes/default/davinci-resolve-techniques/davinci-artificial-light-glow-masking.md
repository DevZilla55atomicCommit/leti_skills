# Artificial Light Glow & Masking

**Source:** Instagram Reel `DF7TxrDtFWL` (Ideas_for_Shooting_Videos)  
**Page:** Color | **Graph:** serial | **Difficulty:** beginner

![Artificial Light Glow & Masking](DF7TxrDtFWL.gif)

## Node Graph Structure

- Adjustment Node
- Power Window
- Blur Node

## Parameters

- **Softness**: High
- **Gain**: Increased for highlights
- **Blending Mode**: Overlay

## Steps to Reproduce in DaVinci Resolve

1. Add an Adjustment Clip on the Color page
2. Use the Power Window (Linear shape) to trace the vertical light sources
3. Increase the Softness of the window edges to create a glow
4. Increase the Gain or Offset to make the light areas pop
5. Apply a Gaussian Blur to the masked area to enhance the light bleed effect
