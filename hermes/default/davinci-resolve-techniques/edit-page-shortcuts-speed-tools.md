## Parameters & Settings

### Key Shortcuts
- **shift_space**: Searchable tool palette (anywhere)
- **opt_drag**: Swap edit (clip over clip)
- **q**: Ripple trim start to playhead
- **w**: Ripple trim end to playhead
- **b**: Blade tool
- **t**: Trim edit mode
- **cmd_d**: Duplicate clip
- **cmd_opt_v**: Paste attributes
