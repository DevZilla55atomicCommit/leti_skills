# High-Contrast Tech Minimalist Look

**Source:** Instagram Reel `C81bQ8yAs4U` (Ideas_for_Shooting_Videos)  
**Page:** Color | **Graph:** serial | **Difficulty:** beginner

![High-Contrast Tech Minimalist Look](C81bQ8yAs4U.gif)

## Node Graph Structure

- Primary Correction
- Curves
- Color Wheels
- Vignette

## Parameters

- **contrast**: +0.15
- **saturation**: 0.85
- **blacks**: crushed down
- **midtones**: slightly desaturated
- **vignette_intensity**: 0.3

## Steps to Reproduce in DaVinci Resolve

1. Apply a slight S-curve in the Curves to deepen shadows and pop highlights.
2. Use the Lift wheel to slightly desaturate the shadows while keeping skin tones warm via Qualifier.
3. Lower the global saturation slightly to achieve a professional, muted aesthetic.
4. Add a subtle circular vignette to draw focus to the center-weighted camera.
