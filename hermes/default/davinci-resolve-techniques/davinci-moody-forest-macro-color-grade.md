# Moody Forest Macro Color Grade

**Source:** Instagram Reel `C-QKQVLMNQ_` (Ideas_for_Shooting_Videos)  
**Page:** Color | **Graph:** serial | **Difficulty:** intermediate

![Moody Forest Macro Color Grade](C-QKQVLMNQ_.gif)

## Node Graph Structure

- Primary Wheels
- Curves
- HSL Qualifier
- Soft Glow

## Parameters

- **saturation**: 0.6
- **contrast**: 1.2
- **shadow_tint**: Teal/Blue
- **highlight_tint**: Warm/Yellow
- **lift_offset**: 0.02

## Steps to Reproduce in DaVinci Resolve

1. Apply a slight lift to the blacks to create a matte/soft shadow look.
2. Use the Curves tool to desaturate overall colors while keeping the green luminance vibrant.
3. In Hue/Saturation curves, push the greens toward cyan/teal for a more moody cinematic tone.
4. Use an HSL Qualifier to isolate the water droplets and increase their Midtone brightness to make them pop.
5. Add a Soft Glow node with a low threshold and high radius to create the ethereal atmosphere around the leaves.
6. Apply a subtle vignette to draw focus to the center foliage.
