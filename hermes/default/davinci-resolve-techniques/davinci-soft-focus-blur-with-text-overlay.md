# Soft Focus Blur with Text Overlay

**Source:** Instagram Reel `C8dBppTpbNQ` (Gimbal_Moves)  
**Page:** Color | **Graph:** serial | **Difficulty:** beginner

![Soft Focus Blur with Text Overlay](C8dBppTpbNQ.gif)

## Node Graph Structure

- Gaussian Blur
- Color Correction

## Parameters

- **blur_radius**: 15
- **softness**: 70

## Steps to Reproduce in DaVinci Resolve

1. In the Color page, add a new node to your node graph
2. Apply Gaussian Blur with radius set to 15 and softness to 70
3. Adjust color grading (e.g., desaturation or vignette) to complement the blurred aesthetic
