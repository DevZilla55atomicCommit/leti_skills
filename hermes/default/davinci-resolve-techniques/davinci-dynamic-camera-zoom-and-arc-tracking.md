# Dynamic Camera Zoom and Arc Tracking

**Source:** Instagram Reel `C0OoMiHN8EW` (Gimbal_Moves)  
**Page:** Edit | **Graph:** serial | **Difficulty:** beginner

![Dynamic Camera Zoom and Arc Tracking](C0OoMiHN8EW.gif)

## Node Graph Structure

- Media Pool
- Dynamic Zoom

## Parameters

- **Dynamic Zoom**: Enabled
- **Ease In**: Fast/Slow
- **Ease Out**: Fast/Slow
- **Zoom Ratio**: Adjusted

## Steps to Reproduce in DaVinci Resolve

1. Place the architectural clip on the timeline
2. Open the Inspector tab
3. Enable the Dynamic Zoom toggle
4. Adjust the 'Ease In' and 'Ease Out' curves to smooth the movement
5. Alternatively use keyframes on the Transform > Position property to create the arc path
