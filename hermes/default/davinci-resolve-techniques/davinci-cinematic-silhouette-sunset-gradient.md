# Cinematic Silhouette & Sunset Gradient

**Source:** Instagram Reel `C-37Ew-PbYk` (Ideas_for_Shooting_Videos)  
**Page:** Color | **Graph:** serial | **Difficulty:** beginner

![Cinematic Silhouette & Sunset Gradient](C-37Ew-PbYk.gif)

## Node Graph Structure

- Primary Node
- Curves
- Color Wheels
- Qualifier Node

## Parameters

- **Contrast**: 1.4
- **Shadows**: -20
- **Midtones**: +10
- **Saturation**: 1.2
- **Hue vs Sat**: Blue-to-Orange shift

## Steps to Reproduce in DaVinci Resolve

1. Lower the Lift slider in the Primary node to turn the structures into solid black silhouettes.
2. Use the Curves tool to create an S-curve, increasing contrast for the sky.
3. Use the Color Wheels to push shadows toward deep purple/blue and highlights toward warm orange/pink.
4. Apply a Qualifier or Hue mask to select the blue lights on the Ferris wheel and increase their saturation and luminance specifically.
5. Add a slight vignette to draw focus to the center of the gradient.
