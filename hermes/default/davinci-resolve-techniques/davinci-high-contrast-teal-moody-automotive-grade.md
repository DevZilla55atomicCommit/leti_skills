# High-Contrast Teal & Moody Automotive Grade

**Source:** Instagram Reel `C5ePsUKS0I8` (Cinematic)  
**Page:** Color | **Graph:** serial | **Difficulty:** beginner

![High-Contrast Teal & Moody Automotive Grade](C5ePsUKS0I8.gif)

## Node Graph Structure

- Primary Balance
- Curves
- Color Wheels
- Text Overlay

## Parameters

- **contrast**: 1.2
- **saturation**: 45
- **lift_tint**: Teal/Blue
- **highlight_tint**: Warm/Yellow
- **midtone_offset**: -0.1

## Steps to Reproduce in DaVinci Resolve

1. Adjust Primaries to deepen blacks and increase contrast for automotive paint depth.
2. Use the Curves tool to slightly desaturate the midtones while keeping highlights vibrant.
3. Apply a blue/teal tint to the Shadows (Lift) to create a moody cinematic atmosphere.
4. Add a subtle warm tint to the Highlights to balance the cool tones of the car.
5. Add a text layer in the Edit page using a bold yellow sans-serif font with high tracking.
