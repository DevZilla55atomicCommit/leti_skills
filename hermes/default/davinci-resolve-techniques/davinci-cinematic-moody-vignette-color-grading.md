# Cinematic Moody Vignette & Color Grading

**Source:** Instagram Reel `DB1W2JnSEi7` (Ideas_for_Shooting_Videos)  
**Page:** Color | **Graph:** serial | **Difficulty:** beginner

![Cinematic Moody Vignette & Color Grading](DB1W2JnSEi7.gif)

## Node Graph Structure

- Primary Wheels
- Power Window
- Vignette
- Color Curves

## Parameters

- **Contrast**: High
- **Saturation**: Desaturated Greens
- **Hue Shift**: Teal and Green shift
- **Edge Softness**: High

## Steps to Reproduce in DaVinci Resolve

1. Import clip and go to the Color page
2. Apply a Power Window (circular) around the subject to increase exposure slightly
3. Lower the shadows using the Primary Color Wheels to create a moody atmosphere
4. Use the Vignette tool to darken the corners and foreground rocks
5. Use Hue vs Sat to shift greens toward a more cinematic/darker tone
6. Increase contrast to make the waterfall mist pop against the dark rocks
