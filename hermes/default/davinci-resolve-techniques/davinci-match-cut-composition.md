# Match Cut (Composition)

**Source:** Instagram Reel `DVzcGUHCO6b` (Ideas_for_Shooting_Videos)  
**Page:** Edit | **Graph:** serial | **Difficulty:** beginner

![Match Cut (Composition)](DVzcGUHCO6b.gif)

## Node Graph Structure

- Wide shot clip
- Close-up clip

## Parameters

- **transition_type**: Hard cut
- **alignment**: Center-weighted

## Steps to Reproduce in DaVinci Resolve

1. Identify a wide shot where the subject/object is centered
2. Find a close-up shot of the same object with similar composition/lighting
3. Place wide shot on Video Track 1
4. Place close-up shot on Video Track 2 immediately following the wide shot
5. Align the frames so the object remains in the same screen position
