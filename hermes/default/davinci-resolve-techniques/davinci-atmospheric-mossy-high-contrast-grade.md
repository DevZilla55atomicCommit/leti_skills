# Atmospheric Mossy High-Contrast Grade

**Source:** Instagram Reel `C_kNPbxMHHd` (Ideas_for_Shooting_Videos)  
**Page:** Color | **Graph:** serial | **Difficulty:** intermediate

![Atmospheric Mossy High-Contrast Grade](C_kNPbxMHHd.gif)

## Node Graph Structure

- Primary Balance
- Curves
- Color Wheels
- Hue Saturation

## Parameters

- **contrast**: 1.4
- **pivot**: 0.45
- **shadow_tint**: Teal/Green
- **highlight_tint**: Yellow/Green
- **saturation**: 1.2

## Steps to Reproduce in DaVinci Resolve

1. Adjust Contrast and Pivot to deepen the shadows in the rock crevices.
2. Use the Lift color wheel to slightly lift the blacks and tint them toward a dark teal or olive green.
3. Use the Gain wheel to add a warm yellow-green tint to the highlights where light hits the moss.
4. Apply a Curves node to create an S-curve for extra punch, emphasizing the mid-tone textures.
5. Use Hue vs Saturation curves to specifically target the green channel, boosting its saturation without affecting skin tones.
6. Add a slight Blur or Glow effect on a separate layer node to simulate the atmospheric haze in the background.
