# Parallax Tracking / Orbital Shot

**Source:** Instagram Reel `DF4vVgXJVEc` (Gimbal_Moves)  
**Page:** Edit | **Graph:** serial | **Difficulty:** intermediate

![Parallax Tracking / Orbital Shot](DF4vVgXJVEc.gif)

## Node Graph Structure

- Camera Editor
- Dynamic Zoom

## Parameters

- **Dynamic Zoom**: Enabled
- **Camera Path**: Linear/Custom
- **Zoom Speed**: Adjusted for movement match

## Steps to Reproduce in DaVinci Resolve

1. Place the clip on the Edit timeline
2. Open the Inspector and select the Camera tab
3. Set a keyframe at the start of the clip
4. Move to the end of the clip and transform the camera position to create a diagonal movement
5. Use the Keyframe editor to smooth out the movement path shown in the diagram
