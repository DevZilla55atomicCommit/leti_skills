# High-Contrast Cinematic Noir Monochrome

**Source:** Instagram Reel `C_InN8wN_AX` (Ideas_for_Shooting_Videos)  
**Page:** Color | **Graph:** serial | **Difficulty:** beginner

![High-Contrast Cinematic Noir Monochrome](C_InN8wN_AX.gif)

## Node Graph Structure

- Primary Wheels
- Curves
- Color Compressor
- Film Grain

## Parameters

- **contrast**: 1.4
- **saturation**: 0.0
- **pivot**: 0.5
- **gamma**: 0.8
- **black_point**: -0.05

## Steps to Reproduce in DaVinci Resolve

1. Reduce Saturation to 0 using the Primary wheels to convert to monochrome.
2. Use the L Curves tool to lift the blacks slightly (faded look) while pulling the shadows down for depth.
3. Increase Contrast to make the white clothing of the subjects pop against the dark background.
4. Apply a soft Glow effect (in Fusion or Color) to the highlights to simulate the decorative string lights.
5. Add a subtle Film Grain overlay to provide a cinematic stock texture.
