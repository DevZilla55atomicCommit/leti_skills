# Dynamic Linear Tracking Keyframing

**Source Reel:** DGgXYntM1c8
**Resolve Page:** Edit

DaVinci Resolve technique extracted from Instagram Reel DGgXYntM1c8.

## Parameters
Position: X-axis adjustment
Keyframe Curves: Linear or Bezier
Zoom: Dynamic scaling


## Steps to Reproduce
1. Import the clip into the Timeline
2. Move the playhead to the start of the desired movement segment
3. Open the Inspector and click the keyframe icon next to Position
4. Move the playhead to the end of the segment
5. Adjust the X-position value to shift the frame horizontally to simulate a track right
6. Adjust keyframe curves in the Keyframe Editor to smooth out the motion
