# Cinematic Teal & Orange Urban Silhouette

**Source:** Instagram Reel `C8HqD4mi4J7` (Ideas_for_Shooting_Videos)  
**Page:** Color | **Graph:** serial | **Difficulty:** intermediate

![Cinematic Teal & Orange Urban Silhouette](C8HqD4mi4J7.gif)

## Node Graph Structure

- Primary Wheels
- Curves
- Color Mixer
- Power Windows

## Parameters

- **contrast**: 1.2
- **pivot**: 0.55
- **shadow_tint**: Teal/Blue
- **highlight_tint**: Amber/Orange
- **saturation**: 45f

## Steps to Reproduce in DaVinci Resolve

1. Apply a slight contrast increase and adjust the pivot to deepen blacks.
2. Use the Lift wheel to push shadows toward a deep teal/blue.
3. Use the Gain wheel to push highlights toward a warm orange/yellow.
4. Use a Power Window on the subject to slightly drop exposure, creating a silhouette effect.
5. Apply a subtle vignette to draw focus to the center of the frame.
6. Use the Curves tool to create a slight S-curve for cinematic roll-off in the midtones.
