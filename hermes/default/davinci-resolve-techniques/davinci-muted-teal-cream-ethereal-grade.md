# Muted Teal & Cream Ethereal Grade

**Source:** Instagram Reel `C8r_dfnIEv8` (Ideas_for_Shooting_Videos)  
**Page:** Color | **Graph:** serial | **Difficulty:** intermediate

![Muted Teal & Cream Ethereal Grade](C8r_dfnIEv8.gif)

## Node Graph Structure

- Primary Balance
- Curves
- Color Wheels
- Soft Glow

## Parameters

- **lift**: Slight cyan/blue tint
- **gain**: Warm orange/yellow tint
- **saturation**: 0.7
- **contrast**: Lowered
- **blacks_point**: Raised (faded look)

## Steps to Reproduce in DaVinci Resolve

1. Use the Lift wheel to raise and slightly tint the blacks, creating a faded look.
2. Decrease overall saturation to achieve a muted palette.
3. Apply a subtle teal tint to the shadows and a warm gold tint to the highlights using Color Wheels.
4. Use the Curves tool to create a slight S-curve, softening the midtones to reduce harsh contrast.
5. Add a Glow node with a high threshold and low opacity to create the ethereal haze around the subject skin and dress.
