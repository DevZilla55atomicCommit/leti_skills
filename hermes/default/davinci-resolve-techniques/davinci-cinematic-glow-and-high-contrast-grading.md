# Cinematic Glow and High Contrast Grading

**Source:** Instagram Reel `C-F6aDFNAxj` (Ideas_for_Shooting_Videos)  
**Page:** Color | **Graph:** serial | **Difficulty:** beginner

![Cinematic Glow and High Contrast Grading](C-F6aDFNAxj.gif)

## Node Graph Structure

- Primary Wheels
- Curves
- Glow
- Color Compressor

## Parameters

- **Contrast**: 1.2
- **Pivot**: 0.45
- **Glow Radius**: 0.50
- **Glow Intensity**: 0.2
- **Saturation**: 1.1

## Steps to Reproduce in DaVinci Resolve

1. Adjust Lift to deepen the blacks for a moody atmosphere.
2. Use the Curves to create a slight S-curve for popping the highlights of the text.
3. Apply a Glow effect node to simulate the light bleed seen in the digital text elements.
4. Use the Color Wheels to push teal into the shadows and orange/purple into the highlights.
5. Increase saturation slightly to match the vibrant nebula colors.
