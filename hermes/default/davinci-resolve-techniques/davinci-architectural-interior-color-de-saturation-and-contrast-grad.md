# Architectural Interior Color De-saturation and Contrast Grading

**Source:** Instagram Reel `C1sUzi7Js_q` (Gimbal_Moves)  
**Page:** Color | **Graph:** serial | **Difficulty:** beginner

![Architectural Interior Color De-saturation and Contrast Grading](C1sUzi7Js_q.gif)

## Node Graph Structure

- Primary Correction
- Color Balance
- Curves (Contrast)

## Parameters

- **Saturation**: 0.0
- **Contrast**: +0.20
- **Midtone Detail**: +15
- **Shadows Pivot**: -0.05

## Steps to Reproduce in DaVinci Resolve

1. Import architectural footage into the Color page
2. Add a Primary Correction node to balance exposure and white points
3. Add a second serial node and drop Saturation to zero for a clean black and white look
4. Use the Curves tool to add contrast and deepen the shadows for a moody aesthetic
5. Apply a soft vignette to draw focus to the central subject or furniture element
