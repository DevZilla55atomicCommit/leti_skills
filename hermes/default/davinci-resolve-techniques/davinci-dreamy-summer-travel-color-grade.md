# Dreamy Summer Travel Color Grade

**Source:** Instagram Reel `DLE7mNIvb2e` (Ideas_for_Shooting_Videos)  
**Page:** Color | **Graph:** serial | **Difficulty:** intermediate

![Dreamy Summer Travel Color Grade](DLE7mNIvb2e.gif)

## Node Graph Structure

- Primary Correction
- HSL Curves
- Color Wheels
- Soft Glow

## Parameters

- **Saturation**: +15
- **Contrast**: +0.1
- **Midtone Tint**: Warm/Yellow
- **Shadows Tint**: Teal/Blue

## Steps to Reproduce in DaVinci Resolve

1. Import clip and go to the Color page.
2. Add a primary correction node to balance exposure and white balance.
3. Add a second node using HSL Curves to increase saturation specifically in greens and skin tones.
4. Add a third node using Color Wheels to push shadows toward teal and highlights toward orange/yellow.
5. Add a fourth node with the Glow effect (low opacity, high softness) to create a dreamy soft-focus look.
6. Apply a slight vignette to draw attention to the center subject.
