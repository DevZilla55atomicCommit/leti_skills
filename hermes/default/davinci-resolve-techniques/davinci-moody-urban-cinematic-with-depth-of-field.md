# Moody Urban Cinematic with Depth of Field

**Source:** Instagram Reel `C8zctEtugyu` (Ideas_for_Shooting_Videos)  
**Page:** Color | **Graph:** serial | **Difficulty:** intermediate

![Moody Urban Cinematic with Depth of Field](C8zctEtugyu.gif)

## Node Graph Structure

- Primary Wheels
- Curves
- Color Warper
- Soft Blur

## Parameters

- **contrast**: 1.2
- **saturation**: 0.7
- **shadow_tint**: Teal/Blue
- **highlight_tint**: Warm/Neutral
- **vignette**: 0.4

## Steps to Reproduce in DaVinci Resolve

1. Apply a circular mask to the subject to isolate them from the background blur.
2. Use the Curves tool to lift the blacks slightly for a faded film look.
3. Shift the shadows toward a teal/cyan hue using the Color Offset wheels.
4. Reduce overall saturation while protecting skin tones using the Qualifier or Hue.
5. Add a subtle vignette to draw focus to the center subject.
