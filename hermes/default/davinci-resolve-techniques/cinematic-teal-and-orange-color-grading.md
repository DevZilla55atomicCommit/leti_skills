# Cinematic Teal and Orange Color Grading

**Source:** Instagram Reel `C_lLHxVgEyc`  
**Resolve Page:** Color  
**Difficulty:** intermediate  
**Node Graph Type:** serial

## Key Nodes
- Primary Correction
- Color Wheels
- Power Windows
- Vignette

## Parameters
- **Temperature:** Warm Highlights
- **Contrast:** High
- **Saturation:** Desaturated Midtones
- **Shadow_Tint:** Teal/Cyan

## Steps to Reproduce
1. Add a primary correction node to balance exposure and contrast
2. Use Color Wheels to push shadows toward a teal/blue tint
3. Use Color Wheels to push highlights toward a warm/orange tone
4. Apply a Power Window to the car to slightly increase exposure and saturation
5. Add a subtle vignette to draw focus to the center
