# Backlit Glow and Mist Enhancement

**Source:** Instagram Reel `C_3qVBiofQP` (Ideas_for_Shooting_Videos)  
**Page:** Color | **Graph:** serial | **Difficulty:** intermediate

![Backlit Glow and Mist Enhancement](C_3qVBiofQP.gif)

## Node Graph Structure

- Primary Correction
- Qualifier Mask
- Soft Glow Node

## Parameters

- **Glow Threshold**: 0.5
- **Glow Radius**: 60
- **Midtone**: 0.3
- **Tint**: Warm Gold

## Steps to Reproduce in DaVinci Resolve

1. Add a primary node to balance exposure and warm up the golden hour tones.
2. Create a qualifier mask to select only the brightest areas of the waterfall and sun.
3. Apply a Soft Glow effect to the masked area to create an ethereal mist look.
4. Use a vignette tool to darken the cave edges and focus attention on the center.
5. Adjust the Mid-tone detail to enhance the highlights in the water spray.
