# Glowing Orb with Text Overlay

**Source:** Instagram Reel `DF0NudHs0LF` (Cinematic)  
**Page:** Fusion | **Graph:** serial | **Difficulty:** intermediate

![Glowing Orb with Text Overlay](DF0NudHs0LF.gif)

## Node Graph Structure

- Glow
- Gradient

## Parameters

- **intensity**: 100
- **radius**: 50

## Steps to Reproduce in DaVinci Resolve

1. Create a new Fusion page in DaVinci Resolve
2. Import the background image and add a circular gradient mask using Gradient node
3. Apply Glow node to the masked layer with intensity set to 100 and radius 50
4. Add text overlay using Text node and position it at the bottom center
