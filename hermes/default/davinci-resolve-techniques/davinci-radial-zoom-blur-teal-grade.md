# Radial Zoom Blur & Teal Grade

**Source:** Instagram Reel `C9-JzvSo5pw` (Ideas_for_Shooting_Videos)  
**Page:** Fusion | **Graph:** serial | **Difficulty:** intermediate

![Radial Zoom Blur & Teal Grade](C9-JzvSo5pw.gif)

## Node Graph Structure

- MediaIn
- Blur
- Color Corre

## Parameters

- **blur_type**: Radial
- **zoom_factor**: 0.75
- **hue_shift**: Cyan-Blue
- **saturation**: 1.2

## Steps to Reproduce in DaVinci Resolve

1. Bring the clip into the Fusion page.
2. Add a Blur node and set the type to Radial Blur.
3. Adjust the center of the radial blur to the focal point where the beams meet.
4. Increase the Blur amount to create the streaking motion effect.
5. Add a Color Corre node to lift the shadows toward a teal/cyan.
6. Increase saturation in the greens to make the background foliage pop.
