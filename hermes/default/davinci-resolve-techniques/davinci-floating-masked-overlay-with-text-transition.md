# Floating Masked Overlay with Text Transition

**Source:** Instagram Reel `DEWsGW_hO-p` (Ideas_for_Shooting_Videos)  
**Page:** Edit | **Graph:** serial | **Difficulty:** beginner

![Floating Masked Overlay with Text Transition](DEWsGW_hO-p.gif)

## Node Graph Structure

- Media Pool
- Text+
- Adjustment Clip

## Parameters

- **Opacity**: 0.8
- **Corner Radius**: 50
- **Transform Zoom**: 1.1

## Steps to Reproduce in DaVinci Resolve

1. Place the main background footage on Track 1
2. Place the overlay clip or secondary footage on Track 2
3. Apply a Crop effect to the overlay clip to create the rounded corners
4. Add a Text+ layer on Track 3 for the HOW caption
5. Keyframe the Position and Zoom of the overlay clip to create a floating effect
