# Multi-layered SFX Composition with Compound Clips

**Source:** Instagram Reel `DAGDedNo2qs` (Ideas_for_Shooting_Videos)  
**Page:** Edit | **Graph:** serial | **Difficulty:** intermediate

![Multi-layered SFX Composition with Compound Clips](DAGDedNo2qs.gif)

## Node Graph Structure

- Compound Clip
- Audio Tracks

## Parameters

- **opacity**: variable for layering
- **audio_layering**: multi-track
- **clip_grouping**: compound for organization

## Steps to Reproduce in DaVinci Resolve

1. Import multiple SFX assets (ambience, impacts, wind) into the Media Pool
2. Layer audio clips on separate audio tracks (A1-A7)
3. Adjust volume and timing of each individual layer to match the visual action
4. Select multiple video clips and right-click to 'Create New Compound Clip' to clean the timeline
5. Apply global effects or color grading to the compound clip layer
