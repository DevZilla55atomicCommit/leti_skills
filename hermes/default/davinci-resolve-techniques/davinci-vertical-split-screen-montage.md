# Vertical Split Screen Montage

**Source:** Instagram Reel `ChC0Ui9lTRf` (Ideas_for_Shooting_Videos)  
**Page:** Fusion | **Graph:** serial | **Difficulty:** intermediate

![Vertical Split Screen Montage](ChC0Ui9lTRf.gif)

## Node Graph Structure

- Split Screen
- Mask

## Parameters

- **split_direction**: vertical

## Steps to Reproduce in DaVinci Resolve

1. Create a new Fusion page and import the three video clips
2. Add Split Screen node with vertical splits set to 3 panels
3. Use Mask nodes on each panel to isolate and position the respective shots
