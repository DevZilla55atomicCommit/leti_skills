# Underwater Atmosphere & Sound Layering

**Source:** Instagram Reel `DANe93RTqZS` (Ideas_for_Shooting_Videos)  
**Page:** Edit | **Graph:** serial | **Difficulty:** intermediate

![Underwater Atmosphere & Sound Layering](DANe93RTqZS.gif)

## Node Graph Structure

- Adjustment Layer
- Color Grade
- SFX Overlay

## Parameters

- **color_tint**: Teal/Cyan
- **particle_density**: High
- **audio_layering**: Multi-track foley/ambience

## Steps to Reproduce in DaVinci Resolve

1. Import base footage and place on Track V1
2. Add an Adjustment Layer on Track V2 for global color grading
3. Apply a teal/cyan tint and increase contrast in the Color Page
4. Overlay particle or bubble assets using Screen or Soft Light blend modes
5. Layer multiple audio tracks including ocean waves, underwater foley, and whooshes to create depth
6. Sync audio whooshes with visual movements or transitions
