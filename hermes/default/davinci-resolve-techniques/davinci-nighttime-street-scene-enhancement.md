# Nighttime Street Scene Enhancement

**Source:** Instagram Reel `C9IY4Nets-o` (Ideas_for_Shooting_Videos)  
**Page:** Color|Edit|Fusion|Fairlight | **Graph:** serial | **Difficulty:** intermediate

![Nighttime Street Scene Enhancement](C9IY4Nets-o.gif)

## Node Graph Structure

- color correction node
- vignette node

## Parameters

- **color correction node**: {'saturation': '1.5', 'contrast': '0.8'}
- **vignette node**: {'center_radius': '20', 'falloff': 'linear'}

## Steps to Reproduce in DaVinci Resolve

1. Adjust color balance for a cooler nighttime ambiance
2. Apply a vignette effect to draw attention to the center of the image
