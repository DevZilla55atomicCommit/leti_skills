# Soft Focus Dreamlike Bokeh Effect

**Source:** Instagram Reel `C9KDgqESViv` (Ideas_for_Shooting_Videos)  
**Page:** Color | **Graph:** serial | **Difficulty:** beginner

![Soft Focus Dreamlike Bokeh Effect](C9KDgqESViv.gif)

## Node Graph Structure

- Gaussian Blur
- Color Wheels
- Soft Glow

## Parameters

- **Blur Radius**: 50.0
- **Mist Amount**: 0.4
- **Contrast**: -0.2
- **Tint**: Teal/Pale Green

## Steps to Reproduce in DaVinci Resolve

1. Add a Gaussian Blur node to completely obscure detail
2. Increase the Blur Radius until the subject is unrecognizable/abstract
3. Add a Soft Glow node or use the Glow effect to bleed highlights into the shadows
4. Use Color Wheels to lift the shadows and tint them a pale green/teal
5. Lower the overall contrast to flatten the image further
