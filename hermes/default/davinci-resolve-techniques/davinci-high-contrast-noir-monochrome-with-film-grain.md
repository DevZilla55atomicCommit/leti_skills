# High-Contrast Noir Monochrome with Film Grain

**Source:** Instagram Reel `DNOK_AUtSn-` (Ideas_for_Shooting_Videos)  
**Page:** Color | **Graph:** serial | **Difficulty:** beginner

![High-Contrast Noir Monochrome with Film Grain](DNOK_AUtSn-.gif)

## Node Graph Structure

- Color Correction
- Curves
- Film Grain Overlay

## Parameters

- **Saturation**: 0
- **Contrast**: 1.4
- **Lift**: -0.05
- **Gain**: 1.15
- **Pivot**: 0.5

## Steps to Reproduce in DaVinci Resolve

1. Drop the Saturation to 0 to remove all color.
2. Use the Curves tool to create a slight S-curve for increased contrast.
3. Adjust the Lift slider down to deepen the shadows (crushed blacks).
4. Increase Gain to pop the highlights on the motorcycle and road reflections.
5. Add a Film Grain node at the end of the chain to add a cinematic texture.
