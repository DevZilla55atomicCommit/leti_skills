# Cinematic Macro High-Contrast Tech

**Source:** Instagram Reel `C9PJuQ7STwH` (Ideas_for_Shooting_Videos)  
**Page:** Color | **Graph:** serial | **Difficulty:** intermediate

![Cinematic Macro High-Contrast Tech](C9PJuQ7STwH.gif)

## Node Graph Structure

- Primary Wheels
- Curves
- Power Windows
- Color Mixer

## Parameters

- **contrast**: 1.2
- **saturation**: 0.35
- **pivot**: 0.45
- **midtone_tint**: 0.02

## Steps to Reproduce in DaVinci Resolve

1. Apply a slight lift to the blacks to create a faded filmic look.
2. Use the Curves tool to create an S-curve for increasing contrast in highlights and shadows.
3. De-aturate the overall image to achieve a moody, tech-focused aesthetic.
4. Use a circular Power Window on the lens to slightly increase exposure and sharpness, drawing the focal point.
5. Use the Color Mixer to subtly cool the shadows while keeping the red lens ring vibrant.
