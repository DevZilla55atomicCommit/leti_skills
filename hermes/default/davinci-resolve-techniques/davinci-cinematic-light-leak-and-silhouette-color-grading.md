# Cinematic Light Leak and Silhouette Color Grading

**Source:** Instagram Reel `DHBdlYbtG8S` (Ideas_for_Shooting_Videos)  
**Page:** Color | **Graph:** serial | **Difficulty:** intermediate

![Cinematic Light Leak and Silhouette Color Grading](DHBdlYbtG8S.gif)

## Node Graph Structure

- Primary Wheels
- Qualifier
- Soft Blur
- Adjustment Clip

## Parameters

- **Saturation**: High
- **Contrast**: Increased
- **Tint**: Magenta/Orange shift
- **Glow**: Soft-focus/Glow effect

## Steps to Reproduce in DaVinci Resolve

1. Import clip and rotate 90 degrees in the Inspector.
2. Use a Qualifier or Power Window to select the silhouette and drop exposure/saturation.
3. Apply a Teal and Orange color grade using Primary Wheels, focusing on magentas in highlights.
4. Add a Light Leak overlay on a track above with Blend Mode set to Screen.
5. Apply a Soft Blur to a duplicate layer to create the dreamy depth-of-field effect.
6. Add a slight grain or vignette to enhance the cinematic aesthetic.
