# Muted Urban Cinematic with Soft Skin Glow

**Source:** Instagram Reel `C_A69YeoLQ_` (Ideas_for_Shooting_Videos)  
**Page:** Color | **Graph:** serial | **Difficulty:** intermediate

![Muted Urban Cinematic with Soft Skin Glow](C_A69YeoLQ_.gif)

## Node Graph Structure

- Primary Correction
- Color Wheels
- Curves
- Glow/Halation

## Parameters

- **saturation**: 0.75
- **contrast**: 1.1
- **midtone_lift**: Warmth
- **shadow_tint**: Cool Teal
- **vignette**: 0.15

## Steps to Reproduce in DaVinci Resolve

1. Adjust exposure and balance using Primaries to achieve a neutral base.
2. Use the Curves tool to slightly reduce overall saturation for a muted look.
3. Apply the Color Wheels to push a slight cool tint into the shadows and a warm tint into the highlights/midtones.
4. Use a Glow node with a low threshold and high softness to soften the highlights and create a dreamy skin effect.
5. Add a subtle vignette to focus attention on the center subject.
