# High-Contrast Urban POV Look

**Source:** Instagram Reel `CfxNhKcgQXB` (Ideas_for_Shooting_Videos)  
**Page:** Color | **Graph:** serial | **Difficulty:** beginner

![High-Contrast Urban POV Look](CfxNhKcgQXB.gif)

## Node Graph Structure

- Exposure
- Curves
- Color Wheels
- Power Window

## Parameters

- **Contrast**: 1.2
- **Saturation**: 0.85
- **Shadows**: Slight Blue Tint
- **Highlights**: Warm/Neutral Tint

## Steps to Reproduce in DaVinci Resolve

1. Adjust Exposure to lift the blacks slightly for a faded look
2. Use the Curves tool to create a subtle S-curve for increased contrast
3. Desaturate global colors to achieve the urban moody aesthetic
4. Apply a subtle blue/cyan tint to the shadows using the Color Wheels (Shadows)
5. Use a Power Window on the camera body to slightly increase its exposure to make it pop
