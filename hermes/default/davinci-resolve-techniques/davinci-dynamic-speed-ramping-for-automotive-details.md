# Dynamic Speed Ramping for Automotive Details

**Source:** Instagram Reel `C4CSow2OgAV` (Gimbal_Moves)  
**Page:** Edit | **Graph:** serial | **Difficulty:** intermediate

![Dynamic Speed Ramping for Automotive Details](C4CSow2OgAV.gif)

## Node Graph Structure

- Adjustment Clip
- Speed Editor
- Motion Blur

## Parameters

- **R Speed**: Variable
- **Motion Blur Amount**: High
- **Dynamic Zoom**: In/Out transition

## Steps to Reproduce in DaVinci Resolve

1. Import luxury car b-roll footage to the timeline
2. Open the Speed Editor tool (Shift+R)
3. Create keyframes to speed up the middle of the clip and slow down the ends
4. Add an Adjustment Clip over the transition
5. Enable Motion Blur in the Inspector or use a Fusion-based plugin to simulate high-speed movement
