# High-Contrast Naturalist Vibrant Saturation

**Source:** Instagram Reel `C5amwpRP8Zg` (Cinematic)  
**Page:** Color | **Graph:** serial | **Difficulty:** beginner

![High-Contrast Naturalist Vibrant Saturation](C5amwpRP8Zg.gif)

## Node Graph Structure

- Primary Balance
- Curves
- Color Wheels
- HSL Qualifier

## Parameters

- **Saturation**: 1.25
- **Contrast**: 1.1
- **Shadows**: Slight blue tint
- **Midtones**: Warm/Yellow tint

## Steps to Reproduce in DaVinci Resolve

1. Apply a primary exposure correction to balance highlights and shadows without clipping.
2. Use the Curves tool to create a subtle S-curve for increasing contrast and lift the blacks slightly for a cinematic look.
3. Use the Hue vs Sat curves to target the greens and increase their saturation specifically to make the foliage pop.
4. In the Color Wheels, add a slight warmth to the midtones and a subtle cool tint to the shadows for color depth.
5. Apply a slight vignette to draw attention to the center subject (tree and man).
