# Low-Key Cinematic Teal & Orange Contrast

**Source:** Instagram Reel `CoVW0LRjwDW` (Ideas_for_Shooting_Videos)  
**Page:** Color | **Graph:** serial | **Difficulty:** intermediate

![Low-Key Cinematic Teal & Orange Contrast](CoVW0LRjwDW.gif)

## Node Graph Structure

- Primary Correction
- Color Balance
- Curves
- Vignette

## Parameters

- **contrast**: 1.25
- **pivot**: 0.55
- **saturation**: 0.8
- **shadow_tint**: Blue/Teal
- **highlight_tint**: Warm/Orange

## Steps to Reproduce in DaVinci Resolve

1. Use Lift/Gamma wheels to deepen shadows and slightly lift the blacks for detail.
2. Apply Parallel Color Wheels to push a teal tint into the shadows and a warm tint into the highlights.
3. Use the Curves tool to create a subtle S-curve for increased contrast.
4. Add a vignette node to draw focus to the subject in the center-left frame.
5. Adjust skin tones using the Qualifier tool to ensure they remain natural despite the heavy color grade.
