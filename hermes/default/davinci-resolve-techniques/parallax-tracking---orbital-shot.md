## Steps to Reproduce

2. Open the Inspector and select the Camera tab
3. Set a keyframe at the start of the clip
4. Move to the end of the clip and transform the camera position to create a diagonal movement
5. Use the Keyframe editor to smooth out the movement path shown in the diagram
