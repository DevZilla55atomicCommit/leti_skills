![Background Rendering via Render Queue](DNguPwhxOeL.gif)

## Node Graph Structure

- Deliver Page
- Render Queue

## Parameters

- **render_setting**: Add to Queue
- **queue_behavior**: Render Background

## Steps to Reproduce in DaVinci Resolve

1. Go to the Deliver page
2. Configure your export settings
3. Click Add to Queue
4. Right-click the job in the Render Queue and select Render Background
5. Continue working on your project while the export processes
