# High-Contrast Architectural Teal & Warm Wash

**Source:** Instagram Reel `C9ut9tuqAhv` (Ideas_for_Shooting_Videos)  
**Page:** Color | **Graph:** serial | **Difficulty:** intermediate

![High-Contrast Architectural Teal & Warm Wash](C9ut9tuqAhv.gif)

## Node Graph Structure

- Primary Balance
- Curves
- Color Wheels
- Power Window

## Parameters

- **contrast**: +0.15
- **saturation**: 0.85
- **shadow_tint**: Teal
- **highlight_tint**: Warm/Gold
- **lift**: -0.015

## Steps to Reproduce in DaVinci Resolve

1. Apply a Primary Balance to increase contrast and slightly desaturate overall colors.
2. Use the Curves tool to create a subtle S-curve, deepening blacks while keeping highlights clean.
3. Use the Color Wheels to push shadows toward a slight teal/cyan hue and highlights toward a warm gold/orange.
4. Apply a Power Window to the signage area to slightly increase exposure and make text pop against the background.
5. Add a slight 'lift' to the blacks to prevent true black clipping, creating a cinematic matte look.
