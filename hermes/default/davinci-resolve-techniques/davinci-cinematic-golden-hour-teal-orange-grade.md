# Cinematic Golden Hour Teal & Orange Grade

**Source:** Instagram Reel `C_6IDHgy0jm` (Ideas_for_Shooting_Videos)  
**Page:** Color | **Graph:** serial | **Difficulty:** intermediate

![Cinematic Golden Hour Teal & Orange Grade](C_6IDHgy0jm.gif)

## Node Graph Structure

- Primary Wheels
- Power Window
- Color Curves

## Parameters

- **Contrast**: 1.2
- **Saturation**: 450
- **Lift**: Teal/Blue shift
- **Gain**: Warm/Orange shift
- **Window Masking**: Soft (Feathering)

## Steps to Reproduce in DaVinci Resolve

1. Add a primary node to adjust contrast and lift the blacks slightly for a matte look.
2. Add a second node and use the Color Wheels to pull the Lift wheel toward teal/blue to tint the shadows.
3. Add a third node with a Power Window over the stadium field and highlights.
4. In the window node, push the Gain wheel toward orange/yellow to enhance the golden hour glow.
5. Use the Curves tool to add a subtle S-curve for increased cinematic mid-tone pop.
