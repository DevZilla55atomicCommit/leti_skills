# Dynamic Zoom Virtual Camera Movement

**Source:** Instagram Reel `DIUA-mUuNTZ` (Gimbal_Moves)  
**Page:** Edit | **Graph:** serial | **Difficulty:** beginner

![Dynamic Zoom Virtual Camera Movement](DIUA-mUuNTZ.gif)

## Node Graph Structure

- Clip Attributes
- Inspector Panel

## Parameters

- **Dynamic Zoom**: Enabled
- **Zoom Type**: In/Out
- **Zoom Speed**: 0.1
- **Ease**: Linear/Smooth

## Steps to Reproduce in DaVinci Resolve

1. Select the clip on the timeline
2. Go to the Inspector panel in the top right
3. Toggle the Dynamic Zoom switch to On
4. In the Viewer, select the Dynamic Zoom tab (bottom left dropdown)
5. Adjust the start and end bounding boxes to define the movement range
6. Adjust the Zoom Speed and Ease settings to refine the motion
