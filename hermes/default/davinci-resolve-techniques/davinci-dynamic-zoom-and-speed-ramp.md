# Dynamic Zoom and Speed Ramp

**Source:** Instagram Reel `DNWSMw4hWW9` (Ideas_for_Shooting_Videos)  
**Page:** Edit | **Graph:** serial | **Difficulty:** beginner

![Dynamic Zoom and Speed Ramp](DNWSMw4hWW9.gif)

## Node Graph Structure

- Adjustment Clip
- Speed Editor

## Parameters

- **Dynamic Zoom**: Enabled
- **Zoom Speed**: 0.5
- **Speed Ramp Curve**: S-Curve

## Steps to Reproduce in DaVinci Resolve

1. Place the BTS clip on the timeline
2. Enable Dynamic Zoom in the Inspector tab
3. Adjust the Green/Red frame sliders to create a subtle push in
4. Open the Curve Editor to add keyframes for a speed ramp
5. Adjust the bezier curves to smooth out the transition between fast and slow motion
