# Selective Color Saturation and Contrast Pop

**Source:** Instagram Reel `DN256MgYrU0` (Ideas_for_Shooting_Videos)  
**Page:** Color | **Graph:** serial | **Difficulty:** beginner

![Selective Color Saturation and Contrast Pop](DN256MgYrU0.gif)

## Node Graph Structure

- Primary Correction
- Qualifier
- Power Window

## Parameters

- **Saturation**: 150
- **Contrast**: 1.20
- **Midtone Detail**: +15

## Steps to Reproduce in DaVinci Resolve

1. Import the clip to the Color page.
2. Add a primary node to adjust overall contrast and lift/gamma/gain balance.
3. Add a second node and use the Qualifier to isolate the lime green color of the boots.
4. Increase saturation specifically on the isolated area to make the green pop.
5. Add a Power Window (soft circular vignette) to draw focus to the center of the bike.
6. Apply a slight sharpening effect to enhance the mechanical details of the motorcycle.
