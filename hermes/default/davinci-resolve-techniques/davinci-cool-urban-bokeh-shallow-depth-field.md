# Cool Urban Bokeh & Shallow Depth Field

**Source:** Instagram Reel `C84oQe8pk4G` (Ideas_for_Shooting_Videos)  
**Page:** Color | **Graph:** serial | **Difficulty:** intermediate

![Cool Urban Bokeh & Shallow Depth Field](C84oQe8pk4G.gif)

## Node Graph Structure

- Exposure
- Primary Balance
- Color Wheels
- Power Windows
- Lens Blur

## Parameters

- **saturation**: -15.
- **contrast**: 1.25
- **temperature**: 6500
- **tint**: 0
- **lens_blur_radius**: 50.0

## Steps to Reproduce in DaVinci Resolve

1. Adjust exposure to drop shadows into blacks while keeping the umbrella bright.
2. Use a Power Window around the umbrella to slightly increase luminance and sharpen the detail.
3. Shift shadows toward a teal/blue hue and highlights toward a subtle orange/warm tone using Color Wheels.
4. Reduce global saturation to achieve a desaturated, cinematic moody look.
5. Apply a Lens Blur effect on a separate node to the background elements to simulate a shallow depth of field.
6. Add a slight vignette to draw focus to the center-weighted umbrella subject.
