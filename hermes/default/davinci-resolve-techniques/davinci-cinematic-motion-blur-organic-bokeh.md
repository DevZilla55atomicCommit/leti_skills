# Cinematic Motion Blur & Organic Bokeh

**Source:** Instagram Reel `C_Ni3eKqDsa` (Ideas_for_Shooting_Videos)  
**Page:** Color | **Graph:** serial | **Difficulty:** intermediate

![Cinematic Motion Blur & Organic Bokeh](C_Ni3eKqDsa.gif)

## Node Graph Structure

- Primary Correction
- Motion Blur
- Soft Glow
- Color Saturation

## Parameters

- **Motion Blur Radius**: 0.50
- **Shutter Angle**: 180
- **Glow Threshold**: 0.4
- **Contrast**: 1.15

## Steps to Reproduce in DaVinci Resolve

1. Import clip and set project resolution to 9:16 vertical format.
2. Apply a Power Window to isolate the bird and slightly increase exposure/sharp.
3. Use the 'Open FX' tab to add a subtle 'Motion Blur' effect if the footage lacks natural shutter speed blur.
4. Add a 'Glow' effect with a high threshold and low opacity to create the dreamy highlights highlights.
5. In the Color Wheels, push the greens toward a teal and warm the highlights for a cinematic contrast.
6. Apply a slight vignette to draw focus to the center where the bird is.
