# Cinematic Moody Teal & Soft Bloom

**Source:** Instagram Reel `C892q0hO5eL` (Ideas_for_Shooting_Videos)  
**Page:** Color | **Graph:** serial | **Difficulty:** intermediate

![Cinematic Moody Teal & Soft Bloom](C892q0hO5eL.gif)

## Node Graph Structure

- Primary Balance
- Color Wheels
- Curves
- Glow/Diffusion

## Parameters

- **lift**: Deep Teal/Blue
- **gain**: Warm/Golden
- **saturation**: Desaturated
- **glow_threshold**: Low
- **glow_radius**: Large

## Steps to Reproduce in DaVinci Resolve

1. Apply a teal tint to the Lift (shadows) using the Primaries color wheels.
2. Use the Gain wheel to add a warm/orange tint to the highlights.
3. Lower the overall saturation and de-saturate the midtones for a muted look.
4. Add a Glow node or use the Diffusion tab to set a high-radius, low threshold to create the hazy light effect.
5. Apply a slight vignette to focus attention on the center subject.
