# Dynamic Gimbal Stabilization and Color Grading

## Overview
This technique focuses on Dynamic Gimbal Stabilization and Color Grading, primarily utilizing the **Color** page in DaVinci Resolve.

### Key Node Graph
- **Type**: serial
- **Key Nodes**: Primary Correction, Power Mask, Color Curves

### Parameters
- **Stabilization**: Camera Edge Mode
- **Contrast**: High Contrast
- **Saturation**: Enhanced for Metallic Tones

### Steps to Reproduce
1. Capture footage using a motorized gimbal to ensure smooth tracking shots
2. Import footage into DaVinci Resolve
3. Use the Stabilization tab in the Inspector to fine-tune any remaining jitter
4. Apply a color grade to enhance the metallic paint of the vehicle
5. Use Power Windows to isolate highlights on the car body
6. Apply a cinematic LUT for the final look
