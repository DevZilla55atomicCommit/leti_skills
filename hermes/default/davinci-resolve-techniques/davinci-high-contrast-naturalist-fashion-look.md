# High-Contrast Naturalist Fashion Look

**Source:** Instagram Reel `C8b8qPXOLjY` (Ideas_for_Shooting_Videos)  
**Page:** Color | **Graph:** serial | **Difficulty:** intermediate

![High-Contrast Naturalist Fashion Look](C8b8qPXOLjY.gif)

## Node Graph Structure

- Primary Wheels
- Curves
- Color Qualifier
- Power Windows

## Parameters

- **contrast**: 1.25
- **saturation**: 1.1
- **midtone_tint**: warm
- **lift_offset**: slight-blue

## Steps to Reproduce in DaVinci Resolve

1. Use Primary Wheels to slightly lift the blacks and compress the highlights for a matte look.
2. Use the Curves tool to create a subtle S-curve for increasing contrast and pop.
3. Use a Color Qualifier to select the green foliage and increase saturation and luminance slightly without affecting skin tones.
4. Apply a Power Window around the subjects to slightly increase exposure and sharpness, making them pop from the background.
5. Add a slight warm tint to the midtones to give skin a healthy and inviting.
