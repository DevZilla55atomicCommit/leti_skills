# Dynamic Dutch Angle with Lens Flare Overlay

**Source Reel:** DFxKFWdNQMr
**Resolve Page:** Edit
**Node Graph Type:** serial
**Difficulty:** beginner

## Description
DaVinci Resolve technique extracted from Instagram Reel DFxKFWdNQMr.

## Key Nodes
- Adjustment Clip
- Fusion Composition
- Color Correction Node

## Parameters
Rotation: -45 degrees
Opacity: 60%
Blend Mode: Screen or Soft Light


## Steps to Reproduce
1. Import the video footage into the Edit page.
2. Add an Adjustment Clip over the footage to apply global transforms.
3. In the Inspector, adjust the Rotation value of the Adjustment Clip to create the Dutch angle.
4. Import a lens flare or light leak overlay on the track above the main footage.
5. Change the Blend Mode of the overlay clip to Screen to integrate the light.
6. Apply a cool-toned grade in the Color page to desaturate shadows and enhance highlights.
