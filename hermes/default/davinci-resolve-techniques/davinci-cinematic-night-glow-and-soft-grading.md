# Cinematic Night Glow and Soft Grading

**Source:** Instagram Reel `DCZXpJLpijt` (Ideas_for_Shooting_Videos)  
**Page:** Color | **Graph:** serial | **Difficulty:** beginner

![Cinematic Night Glow and Soft Grading](DCZXpJLpijt.gif)

## Node Graph Structure

- Primary Correction
- Soft Glow Node
- Curves

## Parameters

- **Glow Gain**: 0.5
- **Glow Threshold**: 0.8
- **Saturation**: -15
- **Contrast**: 1.10

## Steps to Reproduce in DaVinci Resolve

1. Add a primary node to balance exposure and lower shadows for a moody look.
2. Create a serial node and apply the Glow effect.
3. Adjust the Glow threshold to ensure only the brightest lights (window windows, streetlamps) bleed softly.
4. Use the Curves tool to create a slight S-curve for increased contrast.
5. Lower the overall saturation to achieve the desaturated urban teal-and-orange aesthetic.
