# FVPM (Fairlight VFX Pipeline Management)

**Source:** Instagram Reel `DBjXAbVomtU`  
**Resolve Page:** Color|Edit|Fusion|Fairlight  
**Difficulty:** Intermediate  
**Node Graph Type:** serial

## Key Nodes
- Node1: Color Correction
- Node2: Fusion for Visual Effects

## Parameters
- **param1:** LUT (Look-Up Table) for color grading
- **param2:** FX settings for visual effects

## Steps to Reproduce
1. Step 1: Import and organize footage in Fairlight
2. Step 2: Apply LUTs and FX in Color Correction node, then send to Fusion for VFX
