# Dreamy Sunset Silhouette & Pastel Grade

**Source:** Instagram Reel `C8vjMZ3ShfR` (Ideas_for_Shooting_Videos)  
**Page:** Color | **Graph:** serial | **Difficulty:** intermediate

![Dreamy Sunset Silhouette & Pastel Grade](C8vjMZ3ShfR.gif)

## Node Graph Structure

- Exposure
- Color Wheels
- Curves
- Glow
- Vignette

## Parameters

- **contrast**: Low
- **saturation**: High-Warm
- **glow_threshold**: Soft
- **lift_tint**: Teal/Blue
- **highlight_tint**: Orange/Pink

## Steps to Reproduce in DaVinci Resolve

1. Use the Primary Wheels to drop the shadows, ensuring the subject remains a true silhouette.
2. Apply a Color Balance: push highlights toward orange/pink and shadows toward teal/blue.
3. Use the Curves tool to lift the blacks (fading the black point) for a matte look.
4. Add a Glow node with a high Midtone-Detail setting and low opacity to create the hazy, ethereal bleed around the highlights.
5. Add a subtle vignette to draw focus to the center-weighted silhouette.
