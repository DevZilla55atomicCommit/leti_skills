# Ethereal Teal & Orange with Motion Blur

**Source:** Instagram Reel `C9AJSCtxDo0` (Ideas_for_Shooting_Videos)  
**Page:** Color | **Graph:** serial | **Difficulty:** intermediate

![Ethereal Teal & Orange with Motion Blur](C9AJSCtxDo0.gif)

## Node Graph Structure

- Primary Balance
- Curves
- Color Wheels
- Motion Blur

## Parameters

- **Lift**: Lifted slightly for faded blacks
- **Midtones**: Cyan tint
- **Highlights**: Warm/Yellow tint
- **Saturation**: Saturated globally
- **Motion Blur Radius**: High

## Steps to Reproduce in DaVinci Resolve

1. Lift the black point on the Curves tool to create a faded look.
2. Use the Color Wheels to push shadows and midtones toward Teal/Cyan.
3. Add a warm Orange/Yellow tint to the highlights and skin tones.
4. Apply a soft Glow effect in the Blur Sharpen node to enhance the dreamlike atmosphere.
5. Go to the Fusion page and add a Motion Blur node with high shutter angle settings to mimic the handheld camera movement.
