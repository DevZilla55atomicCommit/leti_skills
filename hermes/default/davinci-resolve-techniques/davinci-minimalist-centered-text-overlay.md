# Minimalist Centered Text Overlay

**Source:** Instagram Reel `C9DDwaEvTKX` (Ideas_for_Shooting_Videos)  
**Page:** Edit | **Graph:** serial | **Difficulty:** beginner

![Minimalist Centered Text Overlay](C9DDwaEvTKX.gif)

## Node Graph Structure

- Text Plus

## Parameters

- **Font**: Sans-Serif Bold
- **Color**: #FFFFFF
- **Size**: 0.05
- **Tracking**: 1.2
- **Alignment**: Center

## Steps to Reproduce in DaVinci Resolve

1. Drag a Text Plus clip onto the timeline
2. In the Inspector, enter 'DJI MINI 4 PRO'
3. Set the font to a clean sans-serif style
4. Increase tracking slightly for a cinematic look
5. Position the text exactly in the center of the frame
