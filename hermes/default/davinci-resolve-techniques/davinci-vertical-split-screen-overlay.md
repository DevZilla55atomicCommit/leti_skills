# Vertical Split-Screen Overlay

**Source:** Instagram Reel `Cz87tW7SxNA` (Gimbal_Moves)  
**Page:** Edit | **Graph:** layer_mixer | **Difficulty:** beginner

![Vertical Split-Screen Overlay](Cz87tW7SxNA.gif)

## Node Graph Structure

- Media Pool 1
- Media Pool 2
- Transform

## Parameters

- **Crop Right**: 50
- **Composite Mode**: Normal
- **Zoom**: 1.0

## Steps to Reproduce in DaVinci Resolve

1. Place the final cinematic clip on Track 1
2. Place the BTS/process clip on Track 2 above it
3. Select the Video 2 clip and go to the Inspector
4. Under Cropping, adjust 'Right' to 50 to reveal the clip below
5. Adjust 'Position' and 'Zoom' on both clips to frame the subjects perfectly within their respective halves
6. Optional: Add a transition or border between clips if desired
