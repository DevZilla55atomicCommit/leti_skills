# High-Contrast Cinematic Teal & Red Moody

**Source:** Instagram Reel `C6vhqGwNpJg` (Ideas_for_Shooting_Videos)  
**Page:** Color | **Graph:** serial | **Difficulty:** intermediate

![High-Contrast Cinematic Teal & Red Moody](C6vhqGwNpJg.gif)

## Node Graph Structure

- Primary Balance
- Curves
- Color Wheels
- Qualifier
- Power Window

## Parameters

- **Contrast**: 1.4
- **Pivot**: 0.55
- **Shadows**: -0.02
- **Highlights**: +0.15
- **Saturation**: 0.35

## Steps to Reproduce in DaVinci Resolve

1. Use the Primary wheels to lift the blacks and increase contrast for a deep atmosphere.
2. Apply a Power Window to the headlight to increase exposure and add a slight glow effect.
3. Use the Curves tool to add a subtle blue/teal tint to the midtones.
4. Use the Qualifier to select the red background light and boost its saturation to make it pop.
5. Lower overall global saturation to achieve the desaturated, cinematic look.
