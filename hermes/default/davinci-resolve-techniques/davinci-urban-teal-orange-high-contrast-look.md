# Urban Teal & Orange High-Contrast Look

**Source:** Instagram Reel `C-Pt3mKJF4v` (Ideas_for_Shooting_Videos)  
**Page:** Color | **Graph:** serial | **Difficulty:** beginner

![Urban Teal & Orange High-Contrast Look](C-Pt3mKJF4v.gif)

## Node Graph Structure

- Primary Balance
- Curves
- Color Wheels
- Soft Vignette

## Parameters

- **saturation**: 0.65
- **contrast**: 1.2
- **midtone_tint**: Teal/Cyan
- **highlight_tint**: Warm/Orange
- **lift_offset**: Slight Blue

## Steps to Reproduce in DaVinci Resolve

1. Adjust exposure using Primaries to ensure highlights are bright but not losing detail.
2. Use the Curves tool to create a slight S-curve for increased contrast.
3. In the Color Wheels, push shadows toward a slight teal and highlights toward a warm orange/yellow.
4. Apply a Saturation curve to specifically boost the blue and cyan channels for the sky.
5. Add a soft vignette using a Power Window to draw attention to the center where the phone is.
