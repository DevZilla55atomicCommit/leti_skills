# Warm Naturalist Portrait with Soft Contrast

**Source:** Instagram Reel `C3TWGVKvdWp` (Cinematic)  
**Page:** Color | **Graph:** serial | **Difficulty:** beginner

![Warm Naturalist Portrait with Soft Contrast](C3TWGVKvdWp.gif)

## Node Graph Structure

- Primary Balance
- Color Palette
- Curves
- Color Wheels

## Parameters

- **saturation**: 0.45
- **contrast**: 1.1
- **pivot**: 0.5
- **midtone_offset_warmth**: Warm/Orange
- **vignette**: 0.2

## Steps to Reproduce in DaVinci Resolve

1. Adjust exposure using the Primaries to ensure skin tones are bright but not blown out.
2. Use the Curves to slightly lift the blacks for a matte, cinematic film look.
3. Apply a warm tint to the highlights and midtones using the Color Wheels (Offset slider).
4. Increase saturation specifically in the skin tone range using a Qualifier or Hue curves if necessary.
5. Add a subtle vignette to draw focus inward to the subject face.
