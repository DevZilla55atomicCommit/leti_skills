# Architectural Shadow & Silhouette Grading

**Source:** Instagram Reel `CzwWVDWxElj` (Gimbal_Moves)  
**Page:** Color | **Graph:** serial | **Difficulty:** intermediate

![Architectural Shadow & Silhouette Grading](CzwWVDWxElj.gif)

## Node Graph Structure

- Primary Correction
- Power Window
- Curves

## Parameters

- **Contrast**: High
- **Shadows**: Deepened
- **Highlights**: Protected

## Steps to Reproduce in DaVinci Resolve

1. Import architectural exterior footage into Color page
2. Create primary node to balance exposure and white balance
3. Add Power Window to isolate the barn structure from sky/ground
4. Use Curves to deepen shadows while protecting highlights on roof
5. Add vignette to emphasize the structure and shadow leading lines
