# Cinematic Teal and Orange High-Contrast Grade

**Source:** Instagram Reel `DFHQC0cuy9-`  
**Resolve Page:** Color  
**Difficulty:** beginner  
**Node Graph Type:** serial

## Key Nodes
- Primary Wheels
- Curves
- Color Wheels

## Parameters
- **Contrast:** High
- **Saturation:** Moderate-High
- **Highlights:** Warm/Yellow
- **Shadows:** Deep Blue/Black

## Steps to Reproduce
1. Lower the Lift on the Primary Wheels to create deep, crushed shadows
2. Use the Curves tool to create a slight S-curve for increased contrast
3. Apply a warm yellow/orange tint to the Highlights using the Gain wheel
4. Apply a subtle blue/teal tint to the Shadows using the Lift wheel
5. Add a Vignette to draw focus to the car in the center
