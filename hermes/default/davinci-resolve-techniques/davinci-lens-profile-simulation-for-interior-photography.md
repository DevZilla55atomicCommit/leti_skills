# Lens Profile Simulation for Interior Photography

**Source:** Instagram Reel `C8St4OlJIMV` (Gimbal_Moves)  
**Page:** Color | **Graph:** serial | **Difficulty:** intermediate

![Lens Profile Simulation for Interior Photography](C8St4OlJIMV.gif)

## Node Graph Structure

- Lens Correction
- LUT

## Parameters

- **focal_length**: 18mm
- **distortion_control**: enabled
- **vignette**: adjusted

## Steps to Reproduce in DaVinci Resolve

1. Import footage into DaVinci Resolve
2. Add Lens Correction node to the Color page
3. Set focal length to 18mm and adjust distortion/vignette parameters
4. Apply a LUT for consistent color grading matching the lens effect
