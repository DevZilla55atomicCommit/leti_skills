# Warm Golden Hour Glow & Soft Saturation

**Source:** Instagram Reel `DIJfz_zPosl`  
**Resolve Page:** Color  
**Difficulty:** intermediate  
**Node Graph Type:** serial

## Key Nodes
- Primary Wheels
- Qualifier/Mask
- Power Window
- Curves

## Parameters
- **Temperature:** +1200
- **Tint:** +5
- **Contrast:** 1.20
- **Midtone Detail:** +15
- **Glow Effect:** 0.45

## Steps to Reproduce
1. Increase Temperature and Tint in the Primary Wheels to create a warm base.
2. Use a Power Window with a soft feather to isolate the subject and slightly increase exposure and contrast.
3. Apply a slight S-curve in the Curves tool to deepen shadows while keeping highlights airy.
4. Use the Saturation slider to slightly desaturate greens and blues while keeping the reds in the jacket vibrant.
5. Add a Glow effect on a separate node with a high threshold to create dreamy, hazy highlights.
