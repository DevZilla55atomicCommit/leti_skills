# Gimbal Vertical Tilt Reveal with Stabilization

**Source:** Instagram Reel `C4Hm6kYvoMr` (Gimbal_Moves)  
**Page:** Color | **Graph:** serial | **Difficulty:** beginner

![Gimbal Vertical Tilt Reveal with Stabilization](C4Hm6kYvoMr.gif)

## Node Graph Structure

- Camera Pool
- Stabilizer

## Parameters

- **Stabilizer_Mode**: Perspective
- **Smoothing**: 50.0
- **Zoom**: Slight

## Steps to Reproduce in DaVinci Resolve

1. Record a slow vertical tilt-up using a motorized gimbal
2. Import clip into the Color Color page
3. Open the Stabilizer tool in the Inspector tab
4. Set mode to Perspective
5. Adjust Smoothing slider to eliminate handheld micro-jitters
6. Apply a slight zoom to hide black edges created by stabilization
