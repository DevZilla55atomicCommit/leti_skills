# Power Window Masking for Color Isolation

**Source:** Instagram Reel `C0ZSCJqt3CR` (Gimbal_Moves)  
**Page:** Color | **Graph:** serial | **Difficulty:** beginner

![Power Window Masking for Color Isolation](C0ZSCJqt3CR.gif)

## Node Graph Structure

- Qualifier/Window Node
- Curves Node

## Parameters

- **Window Shape**: Circular/Radial
- **Soft Edge**: High
- **Tracking**: Enabled (if movement exists)

## Steps to Reproduce in DaVinci Resolve

1. Go to the Color page in Da Resolve
2. Select the Window tool and choose the Circular/Radial mask
3. Adjust the mask to fit the triangular window of the A-frame cabin
4. Increase the Soft Edge to blend the mask naturally
5. Use the Primaries Wheels or Curves to increase warmth/saturation inside the masked area
6. Apply a tracker to ensure the mask follows the house if the camera moves
