# Cinematic Foreground Framing & Color Grading

## Parameters

- **aperture**: f/1.4
- **color_balance**: Cool/Teal
- **vignette**: Soft edges

## Steps to Reproduce in DaVinci Resolve

1. Shoot with a close-up foreground object to create a natural frame/bokeh
2. Use a wide aperture (low f-stop) to achieve a shallow depth of field
3. Import clip to DaVinci Resolve and de-expose slightly to recover highlight highlights
4. Apply a cool-toned grade to the shadows to match the moody atmosphere
5. Add a soft vignette to draw focus to the subject (Big Ben)
