# Cinematic High-Contrast Teal & Orange Glow

**Source:** Instagram Reel `C8uyhvjukgw` (Ideas_for_Shooting_Videos)  
**Page:** Color | **Graph:** serial | **Difficulty:** intermediate

![Cinematic High-Contrast Teal & Orange Glow](C8uyhvjukgw.gif)

## Node Graph Structure

- Primary Correction
- Curves
- Color Wheels
- Vignette

## Parameters

- **Contrast**: 1.2
- **Saturation**: 1.1
- **Shadows_Tint**: Teal
- **Highlights_Tint**: Warm/Orange
- **Midtone_Lift**: Slight

## Steps to Reproduce in DaVinci Resolve

1. Adjust exposure and white balance using Primary wheels for a neutral base.
2. Use the S-curve to deepen blacks and pop highlights for contrast.
3. Apply a teal tint to the shadows and a warm/orange tint to the highlights using the Color Wheels.
4. Increase saturation slightly to make the skin tones and brick colors pop.
5. Add a soft circular vignette to focus attention on the camera LCD screen center.
