# High-Contrast Cinematic Warmth

**Source:** Instagram Reel `C8oiKbbvqGj` (Ideas_for_Shooting_Videos)  
**Page:** Color | **Graph:** serial | **Difficulty:** intermediate

![High-Contrast Cinematic Warmth](C8oiKbbvqGj.gif)

## Node Graph Structure

- Primary Balance
- Power Window
- Color Wheels
- Qualifiers

## Parameters

- **Contrast**: +0.15
- **Saturation**: 55
- **Midtone-Tint**: Warm/Orange
- **Shadows-Tint**: Cool/Blue
- **Vignette**: Soft Edge

## Steps to Reproduce in DaVinci Resolve

1. Lift the blacks slightly using the Shadows wheel for a matte look.
2. Use the Curves tool to create a subtle S curve for increased contrast.
3. Apply a Power Window on the subjects to increase exposure and saturation slightly relative to the background.
4. Add a warm orange tint to the Midtones and a slight blue tint to the Shadows to create color color contrast.
5. Use a Qualifier to select the reds in the rug and increase their saturation specifically to make the floor pop.
