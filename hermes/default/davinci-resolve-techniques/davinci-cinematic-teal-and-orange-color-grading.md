# Cinematic Teal and Orange Color Grading

**Source:** Instagram Reel `C79GiZtInJy` (Cinematic)  
**Page:** Color | **Graph:** serial | **Difficulty:** intermediate

![Cinematic Teal and Orange Color Grading](C79GiZtInJy.gif)

## Node Graph Structure

- Primary Correction
- Color Wheels
- Power Windows

## Parameters

- **Contrast**: 1.20
- **Saturation**: 1.5
- **Shadows_Tint**: Teal/Blue
- **Highlights_Tint**: Orange/Gold

## Steps to Reproduce in DaVinci Resolve

1. Add a primary node for exposure and white balance using RGB wheels
2. Use Color Wheels to push shadows toward teal and highlights toward orange
3. Apply a Hue/Saturation curve to desaturate greens while boosting skin tones
4. Use a Power Window around the car to slightly increase exposure and sharpness to make the subject pop
5. Add a vignette to draw focus to the center
