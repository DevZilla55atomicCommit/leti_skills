# Muted Naturalist Overcast Look

**Source:** Instagram Reel `C9zR8qayp0u` (Ideas_for_Shooting_Videos)  
**Page:** Color | **Graph:** serial | **Difficulty:** beginner

![Muted Naturalist Overcast Look](C9zR8qayp0u.gif)

## Node Graph Structure

- Primary Balance
- Curves Contrast
- HSL Saturation
- Color Wheels

## Parameters

- **contrast**: -0.05
- **saturation**: 0.85
- **pivot**: 0.5
- **lift**: slight blue tint
- **gain**: slight warm tint highlights

## Steps to Reproduce in DaVinci Resolve

1. Bring the Lift up slightly to fade the blacks for a flatter cinematic look
2. Use the Curves tool to create a soft S-curve, reducing the overall contrast slightly
3. Use HSL Saturation to desaturate the greens and yellows in the foliage
4. Apply a slight teal/blue tint to the shadows using Color Wheels to balance the sky
5. Add a subtle vignette to draw focus toward the central subject
