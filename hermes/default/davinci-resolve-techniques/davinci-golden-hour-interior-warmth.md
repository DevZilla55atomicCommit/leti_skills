# Golden Hour Interior Warmth

**Source:** Instagram Reel `C6uaj26pVjy` (Ideas_for_Shooting_Videos)  
**Page:** Color | **Graph:** serial | **Difficulty:** intermediate

![Golden Hour Interior Warmth](C6uaj26pVjy.gif)

## Node Graph Structure

- Primary Balance
- Color Wheels
- Curves
- Power Window/Qualifier

## Parameters

- **temperature**: +15.0
- **tint**: -2.0
- **contrast**: 1.2
- **pivot**: 0.5
- **shadow_lift**: Warm Amber
- **highlight_gain**: Golden Yellow

## Steps to Reproduce in DaVinci Resolve

1. Apply a Power Window to isolate the sunlit floor areas and increase exposure and warmth.
2. Increase Temperature in the Global Color Wheels to achieve the golden hour glow.
3. Use the Lift wheel to add a slight teal/cool tint to shadows for complementary color contrast.
4. Adjust the Curves tool to create a subtle S-curve for deeper blacks.
5. Lower the global saturation slightly to maintain a sophisticated, luxury aesthetic.
6. Add a soft bloom or glow effect in Fusion or using the Glow node to soften the highlights hitting the white surfaces.
