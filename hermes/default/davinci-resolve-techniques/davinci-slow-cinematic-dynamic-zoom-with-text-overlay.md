# Slow Cinematic Dynamic Zoom with Text Overlay

**Source:** Instagram Reel `C4359yuJfxv` (Gimbal_Moves)  
**Page:** Edit | **Graph:** serial | **Difficulty:** beginner

![Slow Cinematic Dynamic Zoom with Text Overlay](C4359yuJfxv.gif)

## Node Graph Structure

- Media Pool
- Timeline
- Text+

## Parameters

- **Dynamic Zoom**: Enabled
- **Zoom Speed**: 0.1
- **Text Opacity**: 80%
- **Font**: Sans Serif Bold

## Steps to Reproduce in DaVinci Resolve

1. Import the footage into the Edit page
2. Add a Text+ clip on the track above the video for the numbering
3. Style the text with a bold white sans-serif font
4. Select the video clip and open the Inspector
5. Enable Dynamic Zoom
6. Adjust the Zoom Speed slider to create a slow push-in effect
