# Virtual Gimbal Camera Stabilization

**Source:** Instagram Reel `CxH4rDqLNT_` (Gimbal_Moves)  
**Page:** Color | **Graph:** serial | **Difficulty:** beginner

![Virtual Gimbal Camera Stabilization](CxH4rDqLNT_.gif)

## Node Graph Structure

- Stabilizer

## Parameters

- **Mode**: Camera Lock
- **Smoothing**: 50.0
- **Zoom**: Set to fit frame

## Steps to Reproduce in DaVinci Resolve

1. Import the clip into the Color page
2. Open the Inspector panel on the right
3. Navigate to the Stabilizer tab
4. Set the Mode to 'Camera Lock' for a fixed tripod-like effect
5. Adjust the Smoothing slider until the movement is fluid but natural
6. Increase the Zoom slightly to hide the black edges caused by the crop
