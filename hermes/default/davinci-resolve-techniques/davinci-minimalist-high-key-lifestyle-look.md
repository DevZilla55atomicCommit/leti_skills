# Minimalist High-Key Lifestyle Look

**Source:** Instagram Reel `C82L8qISvzH` (Ideas_for_Shooting_Videos)  
**Page:** Color | **Graph:** serial | **Difficulty:** intermediate

![Minimalist High-Key Lifestyle Look](C82L8qISvzH.gif)

## Node Graph Structure

- Exposure
- Primary Balance
- Curves
- Color Warper
- HSL

## Parameters

- **exposure**: +0.20
- **contrast**: 1.15
- **saturation**: 0.85
- **midtone_tint**: Warm
- **pivot**: 0.45

## Steps to Reproduce in DaVinci Resolve

1. Adjust Lift/Gamma to brighten the shadows for a high-key, airy feel.
2. Lower global saturation slightly to achieve the minimalist aesthetic.
3. Use the Curves tool to create a subtle S-curve for depth without crushing blacks.
4. Apply an HSL qualifier to skin tones to keep them warm while desaturating the background environment.
5. Add a soft glow/bloom effect using the Blur node in the highlights to mimic diffused window light.
