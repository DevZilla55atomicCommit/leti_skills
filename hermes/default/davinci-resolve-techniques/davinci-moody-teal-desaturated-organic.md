# Moody Teal-Desaturated Organic

**Source:** Instagram Reel `C-xnJBpsbna` (Ideas_for_Shooting_Videos)  
**Page:** Color | **Graph:** serial | **Difficulty:** intermediate

![Moody Teal-Desaturated Organic](C-xnJBpsbna.gif)

## Node Graph Structure

- Primary Balance
- Curves
- Color Wheels
- Power Window

## Parameters

- **Temperature**: -15
- **Tint**: +5
- **Saturation**: 35
- **Contrast**: 1.2
- **Shadows_Tint**: Teal/Cyan

## Steps to Reproduce in DaVinci Resolve

1. Lower the overall color temperature toward blue/cyan to establish a cool base.
2. Reduce global saturation to achieve a muted, organic look.
3. Use the Lift wheel to add a teal/cyan tint to the shadows.
4. Apply a Curves node to create a slight S-curve for contrast, while lifting the blacks slightly to prevent them from being too pure black.
5. Use a Hue Qualifier to isolate the greens and desaturate them or shift them toward a darker olive tone.
6. Add a subtle vignette to focus attention on the center of the frame.
