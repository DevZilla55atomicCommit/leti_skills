# Cinematic Teal & Orange Bokeh Glow

**Source:** Instagram Reel `C8JD9B0SbcA` (Ideas_for_Shooting_Videos)  
**Page:** Color | **Graph:** serial | **Difficulty:** intermediate

*No preview GIF available*

## Node Graph Structure

- Primary Correction
- Power Wheels Contrast
- Qualifier Glow
- Vignette & Framing

## Parameters

- **contrast**: 1.45
- **saturation**: 0.6
- **shadow_tint**: #002a3a
- **highlight_tint**: #ff8c00
- **glow_softness**: 0.75
- **vignette_strength**: 0.5

## Steps to Reproduce in DaVinci Resolve

1. Apply a primary node to lift blacks slightly and increase contrast for a moody base.
2. Use Power Wheels to push shadows into deep teal and highlights into a warm orange/gold.
3. Use a Qualifier to select the bright light sources and apply a Glow effect with a soft radius to create the atmospheric bleed.
4. Add a final node with a vertical crop tool or a timeline-based mask to create the central cinematic framing.
5. Add a slight vignette to draw focus to the center-weighted light source.
