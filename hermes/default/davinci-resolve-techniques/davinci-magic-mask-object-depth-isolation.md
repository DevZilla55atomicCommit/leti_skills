## Parameters

- **Mask Mode**: Object
- **Tracking Speed**: High

## Steps to Reproduce in DaVinci Resolve

1. Go to the Color page
2. Create a new serial node
3. Open the Magic Mask effect from the Open FX library
4. Select the 'Object' mask mode
5. Draw a rough stroke over the person/object to isolate
6. Click the Track button to analyze the movement across the timeline
7. Adjust the Refinement settings for a clean edge
8. Apply color grading or effects specifically to the isolated masked subject
