# Moody Urban Desaturated High-Contrast Text

**Source:** Instagram Reel `C4ZgI13N7aL` (Cinematic)  
**Page:** Color | **Graph:** serial | **Difficulty:** beginner

![Moody Urban Desaturated High-Contrast Text](C4ZgI13N7aL.gif)

## Node Graph Structure

- Primary Balance
- Curves
- Color Wheels
- Text Overlay

## Parameters

- **saturation**: -30
- **temperature**: -500
- **lift_offset**: 0.02
- **contrast**: 1.2

## Steps to Reproduce in DaVinci Resolve

1. Lower the overall saturation to create a moody, urban look.
2. Use the Temperature slider to shift the image toward blue/cyan for a cold winter atmosphere.
3. Lift the Lift slightly to fade the blacks and create a matte/cinematic effect.
4. Apply a subtle S-curve to increase contrast in the midtones and highlights.
5. Add a Text+ layer in the Edit page using a high-saturation yellow color to pop against the desaturated background.
