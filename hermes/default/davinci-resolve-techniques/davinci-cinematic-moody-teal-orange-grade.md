# Cinematic Moody Teal & Orange Grade

**Source:** Instagram Reel `C_7iinQsBr8` (Ideas_for_Shooting_Videos)  
**Page:** Color | **Graph:** serial | **Difficulty:** intermediate

![Cinematic Moody Teal & Orange Grade](C_7iinQsBr8.gif)

## Node Graph Structure

- Primary Correction
- Exposure
- Color Wheels
- Power Window Vignette

## Parameters

- **Contrast**: +0.2
- **Saturation**: 0.8
- **Shadows Hue**: Teal/Blue
- **Highlights Hue**: Orange/Warm

## Steps to Reproduce in DaVinci Resolve

1. Add a primary correction node to balance exposure and set White Balance.
2. Add a second serial node to increase contrast and drop the blacks slightly.
3. Add a third node using Color Wheels to push shadows toward Teal and highlights toward Orange.
4. Add a fourth node with a slight desaturation of the overall colors for a moody look.
5. Apply a subtle vignette using a Power Window to draw attention to the camera subject.
