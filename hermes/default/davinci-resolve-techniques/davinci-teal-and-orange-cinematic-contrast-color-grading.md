# Teal and Orange Cinematic Contrast Color Grading

**Source:** Instagram Reel `C3ssC-bNZcQ` (Gimbal_Moves)  
**Page:** Color | **Graph:** serial | **Difficulty:** intermediate

![Teal and Orange Cinematic Contrast Color Grading](C3ssC-bNZcQ.gif)

## Node Graph Structure

- Primary Correction
- Color Wheels
- Power Mask
- Parallel Node

## Parameters

- **Contrast**: High
- **Saturation**: Moderate-High
- **Shadows**: Teal/Blue tint
- **Highlights**: Orange/Warm tint

## Steps to Reproduce in DaVinci Resolve

1. Import clip and add a Primary Correction node to balance exposure and contrast.
2. Use the Lift/Gamma wheels to push shadows toward a deep teal/blue offset.
3. Use the Gain wheel to push highlights toward a warm orange/yellow offset.
4. Apply a Power Mask or Qualifier to isolate the light sources and increase their saturation/warmth.
5. Add a vignette to draw focus to the center-weighted espresso machine.
