# Soft Glow Bloom with Color Grading

**Source:** Instagram Reel `C_p-ZCsyeKI` (Ideas_for_Shooting_Videos)  
**Page:** Color | **Graph:** serial | **Difficulty:** beginner

![Soft Glow Bloom with Color Grading](C_p-ZCsyeKI.gif)

## Node Graph Structure

- Color Correction
- Glow
- Soft Light

## Parameters

- **Glow Threshold**: 0.5
- **Glow Smoothness**: 0.8
- **Blur Radius**: 20
- **Opacity**: 0.4

## Steps to Reproduce in DaVinci Resolve

1. Perform primary color correction to balance exposure and skin tones.
2. Create a new node and apply the Glow effect.
3. Increase the Threshold to ensure only highlights are affected.
4. Increase the Smoothness and Blur Radius to create a dreamy diffusion.
5. Change the node blend mode to Soft Light or Screen to blend the glow naturally.
