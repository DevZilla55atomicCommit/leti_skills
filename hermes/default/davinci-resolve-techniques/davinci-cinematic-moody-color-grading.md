# Cinematic Moody Color Grading

**Source:** Instagram Reel `C_JRTv0s3ug` (Ideas_for_Shooting_Videos)  
**Page:** Color | **Graph:** serial | **Difficulty:** intermediate

![Cinematic Moody Color Grading](C_JRTv0s3ug.gif)

## Node Graph Structure

- Primary Balance
- Color Wheels
- Hue Curves
- Vignette

## Parameters

- **Saturation**: -15.0
- **Contrast**: +1.2
- **Lift**: Teal/Blue
- **Midtones**: Orange/Warm

## Steps to Reproduce in DaVinci Resolve

1. Import footage and normalize exposure using the Primary wheels
2. Increase contrast and slightly drop the overall saturation for a moody look
3. Use Color Wheels to push shadows toward teal/blue tones
4. Push midtones toward warm/orange tones to protect skin tones
5. Apply Hue Curves to refine specific color shifts if necessary
6. Add a soft vignette to draw focus to the subject
