# Golden Hour Silhouette Cinematic

**Source:** Instagram Reel `C7xJahAyc27` (Ideas_for_Shooting_Videos)  
**Page:** Color | **Graph:** serial | **Difficulty:** intermediate

![Golden Hour Silhouette Cinematic](C7xJahAyc27.gif)

## Node Graph Structure

- Exposure
- Curves
- Color Wheels
- Qualifier
- Halation

## Parameters

- **temperature**: +1200
- **saturation**: 55
- **contrast**: 1.2
- **pivot**: 0.55
- **glow_intensity**: 0.35

## Steps to Reproduce in DaVinci Resolve

1. Lower the overall exposure to underexpose the subject, creating a silhouette.
2. Use the Curves node to create a slight S-curve for contrast, lifting the black point slightly for a faded 'filmic' look.
3. Apply a warm tint to the highlights using the Color Wheels (push toward orange/yellow).
4. Apply a subtle teal/blue tint to the shadows to create a complementary color contrast.
5. Add a soft Glow or Halation effect to the highlights to simulate sun-glare diffusion on the lens.
6. Use a Qualifier to isolate the grass and increase the saturation and luminance specifically in the golden tones.
