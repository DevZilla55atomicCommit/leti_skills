# Optimized Export Settings for Video

**Source:** Instagram Reel `DaUiQZsi4Nv`

## Key Nodes

## Parameters
- **Format:** QuickTime
- **Codec:** H.264
- **Resolution:** 1920x1080
- **Frame rate:** 24 fps
- **Encoding Profile:** Auto

## Steps to Reproduce
1. Navigate to the Deliver page (rocket icon) in DaVinci Resolve
2. Select your project name and define file location
3. Set Format to QuickTime
4. Set Codec to H.264
5. Ensure Resolution matches your timeline settings
6. Set Encoding Profile to Auto or High
7. Click Add to Render Queue
8. Click Render All from the Render Queue
