# Vertical Split Screen Color Grade Comparison

**Source:** Instagram Reel `C12n_8UpK7N` (Gimbal_Moves)  
**Page:** Edit | **Graph:** serial | **Difficulty:** beginner

![Vertical Split Screen Color Grade Comparison](C12n_8UpK7N.gif)

## Node Graph Structure

- Video Clip
- Adjustment Node

## Parameters

- **Crop Top**: 50
- **Opacity**: 100%
- **Saturation**: 0.0

## Steps to Reproduce in DaVinci Resolve

1. Place the two video clips on the timeline stacked on top of each other.
2. Select the top clip and go to the Inspector.
3. Use the Crop tool to crop Top to 50% to reveal the bottom clip.
4. Select the bottom clip and go to the Color page.
5. Apply a Black and White effect or reduce Saturation to 0 to create the grayscale look.
6. Add a text overlay using the Title tool for Cinematic Take.
