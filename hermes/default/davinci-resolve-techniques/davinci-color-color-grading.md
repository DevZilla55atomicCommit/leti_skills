# Color Grading (Color)

## Overview
Combined 2 techniques from Instagram Reels for color page.

## Resolve Page
Color

## Node Graph Type
serial

## Key Nodes
- Curves
- LUT
- Node Graph
- Primaries

## Parameters
- Contrast: 1.000
- LUT Type: 3D

## Steps to Reproduce
1. Open DaVinci Resolve and import Slog3 footage
2. Set up a serial node graph with Primary Color Wheels
3. Adjust Contrast parameter in the Primaries section
4. Add LUT node to the color page
5. Connect LUT before Curves node
6. Adjust LUT intensity and curves for desired look

intermediate
