# Digital Camera Stabilization

**Source:** Instagram Reel `C3_QOY-Jgfd` (Gimbal_Moves)  
**Page:** Color | **Graph:** serial | **Difficulty:** beginner

![Digital Camera Stabilization](C3_QOY-Jgfd.gif)

## Node Graph Structure

- Stabilizer

## Parameters

- **Mode**: Perspective
- **Smoothing**: 50.0
- **Locking**: Checked

## Steps to Reproduce in DaVinci Resolve

1. Import the handheld gimbal footage into the timeline
2. Go to the Color page
3. Open the Stabilizer tab
4. Select the Perspective mode to handle camera rotation and movement
5. Adjust the Smoothing value to remove micro-jitters
6. Click Stabilize
