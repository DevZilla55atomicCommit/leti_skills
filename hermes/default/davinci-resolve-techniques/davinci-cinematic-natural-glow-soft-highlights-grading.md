# Cinematic Natural Glow & Soft Highlights Grading

**Source:** Instagram Reel `DEPnM-Es_Lj` (Ideas_for_Shooting_Videos)  
**Page:** Color | **Graph:** serial | **Difficulty:** intermediate

![Cinematic Natural Glow & Soft Highlights Grading](DEPnM-Es_Lj.gif)

## Node Graph Structure

- Primary Correction
- Glow
- Curves
- Exposure

## Parameters

- **Contrast**: 1.2
- **Pivot**: 0.55
- **Glow Radius**: 60.0
- **Glow Threshold**: 0.4
- **Saturation**: 480

## Steps to Reproduce in DaVinci Resolve

1. Adjust exposure and white balance in Primary nodes for a neutral base
2. Use Curves to slightly lift the blacks and compress the highlights for a matte look
3. Add a Glow node with a high threshold to soften the light coming through the windows
4. Apply a subtle warm tint to the highlights using the Color Wheels wheels
5. Desaturate the mid-tones slightly to maintain a clean, modern aesthetic
