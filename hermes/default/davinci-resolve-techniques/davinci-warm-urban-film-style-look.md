# Warm Urban Film-Style Look

**Source:** Instagram Reel `C8wabN1JwV5` (Ideas_for_Shooting_Videos)  
**Page:** Color | **Graph:** serial | **Difficulty:** intermediate

![Warm Urban Film-Style Look](C8wabN1JwV5.gif)

## Node Graph Structure

- Primary Balance
- Curves
- Color Wheels
- Film Glow

## Parameters

- **Contrast**: 1.2
- **Saturation**: 0.8
- **Lift**: Lifted (faded)
- **Temperature**: Warm/Orange
- **Tint**: Slight Teal in shadows

## Steps to Reproduce in DaVinci Resolve

1. Apply a Dutch angle tilt in the Edit page to match the dynamic composition.
2. Use the Curves node to slightly lift the black point for a faded matte look.
3. Adjust the S-curve to increase contrast slightly while keeping overall saturation low.
4. Use the Color Wheels to push warm/orange tones into the highlights and a subtle teal/blue into the shadows.
5. Add a Film Glow effect with low threshold to soften the highlights on the buildings.
6. Add a lens flare overlay if the original footage does not have enough.
