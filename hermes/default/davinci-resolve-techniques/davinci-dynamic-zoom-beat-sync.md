# Dynamic Zoom Beat Sync

**Source:** Instagram Reel `DHguGVQyDLE` (Ideas_for_Shooting_Videos)  
**Page:** Edit | **Graph:** serial | **Difficulty:** beginner

![Dynamic Zoom Beat Sync](DHguGVQyDLE.gif)

## Node Graph Structure

- Video Clip
- Adjustment Layer

## Parameters

- **Dynamic Zoom**: Enabled
- **Ease In**: Medium
- **Ease Out**: Medium

## Steps to Reproduce in DaVinci Resolve

1. Import footage to the timeline and cut it at the beat where you want the effect to occur
2. Open the Inspector and navigate to Dynamic Zoom
3. Enable the Dynamic Zoom toggle
4. Adjust the Green and Red rectangles to create a subtle zoom-in effect
5. Use the ease curves in the key editor to make the movement smooth
6. Add a motion blur effect via an adjustment layer to enhance the transition
