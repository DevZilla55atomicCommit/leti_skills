# Dark Scene (Color)

## Overview
Combined 2 techniques from Instagram Reels for color page.

## Resolve Page
Color

## Node Graph Type
serial

## Key Nodes
- Curves
- Glow
- LUT
- Primary Correction

## Parameters
- LUT: Warm Tone LUT
- Curves: S-Curve
- Glow Intensity: High

## Steps to Reproduce
1. Apply a warm LUT to the clip for initial tonal adjustment
2. Adjust curves to enhance midtones and shadows with warm tones
3. Apply a dark-themed LUT to the footage for base color correction
4. Add a Glow node with high intensity to enhance light streaks in low-light scenes
