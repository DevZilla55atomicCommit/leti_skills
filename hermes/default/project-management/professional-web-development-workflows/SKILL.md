# Professional Web Development Workflows

## Overview

This umbrella skill consolidates the core workflows for professional web development in the Hermes environment. It serves as a navigation hub for:

- Specification-driven development
- Incremental implementation
- Test-driven development
- Context engineering
- Git workflow and versioning
- Code review and quality assurance
- Code simplification
- Skill authoring and management

## When to Use

- Starting a new feature or project
- Need to coordinate multiple workflows
- Seeking guidance on best practices
- Onboarding new team members

## User Preferences
- **Conciseness**: Deliver responses with minimal verbosity; drop explanatory prose that does not add actionable value.
- **Directness**: Answer the question directly; omit process narratives unless explicitly requested.
- **Precision**: Focus on actionable output; avoid redundant details or repeated explanations.
- **Flow**: Maintain a tight sequence—no preamble, no reiteration, no “as an AI language model…”.
- **Style**: Prefer markdown tables/lists for clarity; avoid long paragraphs when enumerated points suffice.
