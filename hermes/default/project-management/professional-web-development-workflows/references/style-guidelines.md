# Style Guidelines for Concise Responses

## Core Principles

1. **Directness**: Answer the question explicitly first; omit preamble.
2. **Conciseness**: Deliver only essential details; avoid redundant explanations.
3. **Precision**: Focus on actionable outputs or clear decisions.
4. **Flow**: Maintain a tight sequence—no digressions.
5. **Formatting**: Prefer markdown tables/lists for structured clarity; avoid long paragraphs.

## When to Apply

- Any written response to user queries
- Code reviews, documentation, or procedural explanations
- Incremental updates or checklists
